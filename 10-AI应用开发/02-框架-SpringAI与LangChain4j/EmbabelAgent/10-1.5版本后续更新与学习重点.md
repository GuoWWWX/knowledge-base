# Embabel Agent 1.5 后续更新与学习重点

## 1. 和现有笔记是什么关系？

本区 [[02-环境搭建与第一个Agent]] 等笔记使用 **1.5.0** 作为示例基线，不需要为了追新直接修改它们的依赖。官方发布页显示，截至 2026-10-30 已发布 **1.5.4**。要升级工程时，应先阅读 1.5.1 到 1.5.4 的变更，检查 Spring、模型适配器和项目中实际使用的 API，再运行原有测试。

## 2. 值得继续学习的变化

| 方向 | 官方发布记录中的变化 | 学习时关注什么 |
| :--- | :--- | :--- |
| 类型化决策与分类 | 1.5.4 增加 decision / classification 服务契约、类型化规格与结果、LLM 支持 | 决策输入输出如何约束，和已有 Action / Goal 规划分别负责什么 |
| 模型与协议接入 | 1.5.4 增加 OpenAI 兼容模型的 Responses API 构建支持，并更新若干模型集成 | 确认具体模型和服务端支持的协议，比较结构化输出与工具调用行为 |
| 工具与运行事件 | 1.5.4 修复工具重复注册、Process 监听器事件发布，并补充远端 MCP 工具组文档 | 检查工具名冲突、MCP 授权及事件是否完整，给关键行为加回归测试 |

这些是发布记录中的能力或修复，不代表旧笔记的 1.5.0 示例已经自动适配 1.5.4。决策服务是否适合替换现有业务判断，需要结合结果可验证性与成本单独评估。

## 3. 建议的学习顺序

先完成 Blackboard、Action、Goal 与 Planner 的原有主线；再读 1.5.4 发布说明，选一个实际分类任务观察类型化输入输出，最后用测试比较升级前后的工具、事件和模型返回行为。

# uv包管理与环境

> [!abstract] 一句话总结
> `uv` 是 Python 项目的包管理、虚拟环境和脚本运行工具；对 Java 开发者来说，可以把它理解成 Maven/Gradle + 本地 JDK 版本管理的一部分，用来快速跑通 FastAPI、LangChain、RAG 示例。

## 🎯 本节定位

- **本章第 2 课**：承接 [[01-Python速查-Java视角]] 的语法速查，解决“环境怎么搭、依赖怎么管”。
- **延伸**：[[03-asyncio异步基础]]、[[04-FastAPI起服务]] 会反复用到本课的命令。

## 📌 这是什么

`uv` 解决的是 Python 项目最容易混乱的三件事：

1. 当前项目用哪个 Python 版本。
2. 依赖装在哪里，版本是否可复现。
3. 用什么命令运行脚本、测试和服务。

Java 项目通常依赖 `pom.xml`、`build.gradle` 和本机 JDK；Python AI 项目通常看 `pyproject.toml`、`.venv/`、`uv.lock` 和 `.env`。

## 🧠 Java 对照

| Java / Maven | Python / uv | 记忆点 |
| ------------ | ----------- | ------ |
| `pom.xml` | `pyproject.toml` | 项目元信息和依赖 |
| `mvn test` | `uv run pytest` | 在项目环境里跑测试 |
| `mvn spring-boot:run` | `uv run uvicorn main:app --reload` | 启动本地服务 |
| Maven 本地仓库 | uv 缓存 | 下载包会复用缓存 |
| JDK 版本 | Python 版本 | AI 项目常卡在 `3.10/3.11/3.12` |
| `application.yml` | `.env` | 本地密钥和连接串 |

## ⚙️ 环境命令

新建项目：

```bash
uv init ai-python-demo
cd ai-python-demo
uv python pin 3.11
uv add fastapi uvicorn pydantic openai
uv run python --version
```

接手已有项目：

```bash
uv sync
uv run python main.py
uv run pytest
uv run ruff check .
```

常用排查：

```bash
uv tree
uv pip list
uv run python -c "import sys; print(sys.executable)"
```

## 💻 最小示例

`main.py`：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health() -> dict[str, str]:
    return {"status": "ok"}
```

运行：

```bash
uv add fastapi uvicorn
uv run uvicorn main:app --reload
```

浏览器打开 `http://127.0.0.1:8000/docs`，能看到 Swagger 页面就说明环境、依赖和服务入口都通了。

## 🤖 AI 生态落点

- 跑 LangChain、LlamaIndex、FastAPI 示例时，先用 `uv sync` 复现作者环境。
- RAG 项目常见依赖是 `pydantic`、`fastapi`、`openai`、`chromadb`、`langchain`、`sentence-transformers`。
- 本地模型、向量库、代理地址和 API Key 通常放在 `.env`，再由 `python-dotenv` 或框架读取。
- 写项目 README 时，把 `uv sync`、`.env.example`、`uv run ...` 三行命令放在最前面，别人更容易复现。

## ⚠️ 踩坑与注意事项

- 不要混用系统 Python、Conda、`pip install` 和 `uv add`，否则包可能装到另一个解释器里。
- `ModuleNotFoundError` 先查 `uv run python -c "import sys; print(sys.executable)"`，确认运行解释器来自当前项目。
- `uv.lock` 要提交到仓库，团队协作时才能锁住依赖版本。
- 老项目只有 `requirements.txt` 时，可以先 `uv init`，再 `uv add -r requirements.txt`。
- Windows 路径有中文通常能跑，但某些原生依赖编译失败时，优先换短路径或使用官方 wheel。

## 🎯 面试 / 项目用途

> [!question] 高频问题
> - Q: `uv` 和 `pip` 的区别是什么？
>   - A: `pip` 主要负责安装包；`uv` 同时覆盖虚拟环境、依赖解析、锁文件和命令运行，更像项目级工具。
> - Q: 接手一个 Python AI 项目第一步看什么？
>   - A: 看 `README.md`、`pyproject.toml`、`uv.lock`、`.env.example`，再用 `uv sync` 和最小命令跑通。
> - Q: 项目里为什么要固定 Python 版本？
>   - A: AI 依赖常带原生扩展或框架版本约束，Python 小版本不同可能导致安装或运行失败。

项目里可以把 `uv` 用在：快速复现开源 demo、给 FastAPI RAG 服务写本地启动脚本、CI 中运行 `uv sync && uv run pytest`。

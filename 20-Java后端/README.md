## 📄 本领域文档约定

- **知识笔记**：优先沉淀到当前章节索引下的实际主题文件，例如 [[01-Java核心/_index]]、[[02-JVM/_index]]、[[04-Spring生态/_index]]
- **文件编号**：每个知识区按 `_index.md` 的学习顺序从 `01` 连续编号，例如 `01-JVM内存区域.md`；`_index.md` 和 README 不参与编号
- **跨模块串联**：完成单点知识后进入 [[10-知识串联与专题/_index]]，按请求、事务、异步、治理和排障链路复习
- **重原理 + 重源码**：Java 后端面试和实战都看深度，笔记要讲清"为什么"，不止"是什么"
- **按需画图**：内存布局、GC 流程、并发时序和架构关系适合用 mermaid 表达；简单结论直接说明
- **示例边界**：关键代码不等于完整项目；版本前提要写明，性能数据须附测试条件，未验证的标为待实测
- **关联 AI 领域**：很多 Java 能力（并发、JVM、分布式）是 AI 应用工程化的底座，可与 [[../10-AI应用开发/README|AI 领域]] 互链

# 11 · 设计模式与设计原则：从面向对象解耦到企业级代码重构

本章围绕软件工程的核心诉求——**高内聚、低耦合、可维护与可扩展**，从七大面向对象设计原则出发，以生产高频模式为主线，并通过两篇扩展阅读完整覆盖 GoF 创建型 5 种、结构型 7 种、行为型 11 种，结合 JDK、Spring、MyBatis 等主流框架源码与复杂业务重构案例，建立清晰的设计模式应用边界。

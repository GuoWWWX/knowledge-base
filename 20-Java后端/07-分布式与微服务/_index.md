# 07 · 分布式与微服务

> [!info] 本区说明
> 分布式学习主线是：网络不可靠、节点会失败、时钟会漂移，所以一致性、锁、ID、事务和治理都要明确故障语义。

## 🧭 学习路径

- 先读 CAP/BASE 和一致性算法，建立取舍语言。
- 再读 ID、锁、分布式事务，掌握业务正确性工具箱。
- 最后读服务治理、限流熔断降级和链路追踪，补齐运行时治理。

## ✅ 验收标准

- 能说明 CP/AP 在具体接口上的选择。
- 能设计 TCC/Saga 的幂等、空回滚、防悬挂和补偿。
- 能用 trace、指标和日志定位跨服务慢调用。

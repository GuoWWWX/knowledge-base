# 🌱 04 · Spring 生态（从入门到架构精通指南）

> [!tip] 学习心法
> **Spring 的核心精髓是“把对象的创建与关系的维护交出去（IoC），把通用的逻辑与横切的关注点抽出来（AOP）”。**
> 本模块全面剔除干瘪晦涩的“技术规格书”文风，采用 **【生活化比喻 + 翻车现场代码（Why） + 底层图解（Under the hood） + 生产防坑军规】** 的四步模型编写。示例以 **Java 21 LTS + Spring 6.x / Spring Boot 3.x** 为基准。

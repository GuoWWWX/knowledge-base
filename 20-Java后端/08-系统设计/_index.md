# 08 · 系统设计

> [!info] 本区说明
> 系统设计学习主线是：先算容量和 SLO，再拆读写路径、状态机、缓存、异步、分片、降级和观测。

## 🧭 学习路径

- 通用能力先读高并发、高可用、缓存架构。
- 案例题再读秒杀、短链、即时通讯、订单。
- 每个设计都要说清数据模型、关键流程、失败模式和验证指标。

## ✅ 验收标准

- 能做容量估算并指出瓶颈。
- 能画核心链路和数据状态机。
- 能列出超卖、重复消费、缓存脏读、消息丢失等故障兜底方案。

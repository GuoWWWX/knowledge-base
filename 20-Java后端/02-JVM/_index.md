## 🧪 验证目标

- 能拿一段 GC 日志说出分配率、晋升、停顿来源和是否需要调参。
- 能根据 `OutOfMemoryError` 文案判断堆、元空间、直接内存、线程或本地内存方向。
- 能用 `jcmd`、`jstack`、`jstat`、JFR、Arthas 组合完成一次 CPU 高、内存涨、接口慢的定位链路。

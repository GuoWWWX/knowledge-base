# ⚙️ 02 · JVM

> [!info] 本区心智模型
> JVM 是 Java 程序跨平台运行的基石。核心体系涵盖：运行时数据区划分、对象生命周期与内存布局、垃圾回收机制、类加载与 JIT 即时编译，以及生产排障与性能调优。各篇按技术依赖层层递进，建议按序阅读。

# 06 · 中间件

> [!info] 本区说明
> 中间件学习主线是：消息、注册配置、网关和缓存如何把单体能力变成可治理的分布式基础设施。

## 🧭 学习路径

- 消息队列先区分 Kafka 与 RocketMQ 的存储和消费模型。
- 可靠性、顺序和幂等是所有 MQ 面试的落点。
- 注册中心、配置中心、网关要和服务治理、限流、追踪连起来复习。

## ✅ 验收标准

- 能画出 Kafka/RocketMQ 的生产、存储、消费和重试流程。
- 能解释配置动态刷新边界和误发布回滚。
- 能设计网关路由、认证、限流、灰度和观测链路。

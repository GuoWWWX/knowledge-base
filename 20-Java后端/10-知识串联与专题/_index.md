# 10 · 知识串联与高阶专题：Java 后端全链路体系贯通

在前面的章节中，我们分别学习了 Java 基础、JVM、并发编程、Spring 生态、MySQL 数据库、中间件以及分布式微服务。然而在实际生产研发与架构面试中，这些技术从来不是孤立存在的——一次简单的用户下单请求，就会同时横跨网关、Tomcat 线程池、Spring AOP 事务、数据库连接池、InnoDB 锁与消息队列。

本章通过 **8 个全链路纵深专题**，打破单点知识的边界，按“底层硬件与 JVM -> 单机并发与异步 -> Web 请求与事务一致性 -> 微服务治理与线上排障”的脉络，将整个 Java 后端知识体系串联成一张完整的工程网络。

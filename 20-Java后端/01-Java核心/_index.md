## 🧭 精通路线（为什么是这个顺序）

> 每一篇的“本节定位”小节都写了上一课衔接与延伸阅读，按编号顺序学即可，不用跳。

1. **先打地基（01→03）**：[[01-泛型与类型擦除]] 讲清类型系统（擦除、PECS），[[02-异常处理最佳实践]] 讲清错误处理，[[03-String与字符串常量池]] 讲清最常用类型——后续所有章节的地基。
2. **再组织数据（04 集合框架，全章第 4~9 课）**：进入 [[04-集合框架/_index|04 · 集合框架]] 子目录，先读总纲 [[04-集合框架/01-核心机制与选型|01-核心机制与选型]]（家族树、选型表、公共机制），再按实现分篇 [[04-集合框架/02-List实现-ArrayList与LinkedList|02-List]] → [[04-集合框架/03-Set实现-HashSet与TreeSet|03-Set]] → [[04-集合框架/04-HashMap原理与扩容|04-HashMap]] → [[04-集合框架/05-Map实现-LinkedHashMap与TreeMap|05-Map变体]] → [[04-集合框架/06-Queue实现-ArrayDeque与PriorityQueue|06-Queue]]，最后 [[04-集合框架/07-排序详解|07-排序详解]] 把排序讲透。每篇直接把关键源码贴进文档，学完会选会用、能答源码题。
3. **处理与移动数据（10→11）**：[[10-Lambda与Stream]] 用声明式流水线处理集合，[[11-IO与NIO]] 处理文件与网络读写。
4. **理解运行期机制（12→13）**：[[12-反射与动态代理/_index|12-反射与动态代理]] 讲框架如何在运行期检查、调用、增强对象，[[13-注解与注解处理器]] 讲框架的配置入口——Spring 章节的必备前置。
5. **现代语法收尾（14→15）**：[[14-Java新特性-Record与密封类]] 改善建模，[[15-虚拟线程]] 讲清"是什么、为什么、怎么写"即可收尾本章；调度器、pinning 代价、上线压测等深入内容在 [[20-Java后端/03-并发编程/11-虚拟线程深入|并发 11 · 虚拟线程深入]]，学完并发章前置（线程池、锁）再看。
6. **速查收尾（16）**：[[16-集合速查]] 把集合相关的选型、复杂度、易错点集中成一张速查表，写代码或报错时回来查。

## 🧪 验证目标

- 看到需求能直接说出用哪个集合类并写出代码（选型总表见 [[04-集合框架/01-核心机制与选型|集合总纲]]）。
- 能默写并讲清 ArrayList 扩容、HashSet 委托、HashMap 拆链、LinkedHashMap LRU、PriorityQueue 上浮的关键源码段。
- 能写出最小代码复现泛型擦除、HashMap key 变异、try-with-resources suppressed 异常和 ByteBuffer `flip` 错误。
- 能答出本章每篇的"面试问题"小节（高频 + 追问）。

# 📘 01 · Java 核心

> [!info] 本区说明
> 语言基础（泛型、异常、String）、集合框架、数据处理（Lambda/Stream）、IO/NIO、运行期机制（反射/动态代理/注解）与现代 Java 新特性（Record/密封类/虚拟线程）。

## 📚 知识笔记清单（按学习顺序编号，顺着编号读即可）

- [ ] [[01-泛型与类型擦除]] — 类型系统地基：集合、Lambda、反射全都建立在泛型之上
- [ ] [[02-异常处理最佳实践]] — 错误处理地基：后续 IO 资源关闭、框架排查都依赖异常语义
- [ ] [[03-String与字符串常量池]] — 最高频使用类：不可变性、常量池、拼接性能
- [ ] [[04-集合框架-List-Map-Set源码]] — 数据组织：List/Set/Map 的选型与源码
- [ ] [[05-HashMap原理与扩容]] — 数据组织深挖：哈希、冲突、扩容的完整原理
- [ ] [[06-Lambda与Stream]] — 数据处理：函数式接口、惰性流水线、并行边界
- [ ] [[07-IO与NIO]] — 数据移动：流、Buffer/Channel/Selector、零拷贝、句柄泄漏
- [ ] [[08-反射与动态代理]] — 运行期机制（上）：框架（Spring AOP、RPC）的地基
- [ ] [[09-注解与注解处理器]] — 运行期机制（下）：注解如何被编译期/运行期读取
- [ ] [[10-Java新特性-Record与密封类]] — 现代建模：不可变数据载体与可穷尽的继承边界
- [ ] [[11-虚拟线程]] — 并发主题入口：轻量线程、pinning、容量边界（深入在并发章节）

## 🧭 精通路线（为什么是这个顺序）

> 每一篇的“本节定位”小节都写了上一课衔接与延伸阅读，按编号顺序学即可，不用跳。

1. **先打地基（01→03）**：[[01-泛型与类型擦除]] 讲清类型系统如何工作（擦除、通配符、PECS），[[02-异常处理最佳实践]] 讲清错误如何分类与传播，[[03-String与字符串常量池]] 讲清最常用类型的内存与性能——后续所有章节都建立在这三课之上。
2. **再组织数据（04→05）**：[[04-集合框架-List-Map-Set源码]] 先建立 List/Set/Map 的整体选型观（含 equals/hashCode 契约），[[05-HashMap原理与扩容]] 再深挖哈希表这一个最常用、面试最深的数据结构。
3. **处理与移动数据（06→07）**：[[06-Lambda与Stream]] 用声明式流水线处理集合，[[07-IO与NIO]] 处理文件与网络读写（try-with-resources 来自 02，Buffer 状态机是 NIO 核心）。
4. **理解运行期机制（08→09）**：[[08-反射与动态代理]] 讲框架如何在运行期检查、调用、增强对象，[[09-注解与注解处理器]] 讲框架的配置入口——两者是后面 Spring 章节的必备前置。
5. **现代语法收尾（10→11）**：[[10-Java新特性-Record与密封类]] 用现代语法改善建模，[[11-虚拟线程]] 作为并发主题入口；虚拟线程的深入内容在 03-并发编程 章节。

## 🧪 验证目标

- 能从源码入口解释一次 `put/get/remove`、一次反射调用、一次 Stream 终端操作的真实执行路径。
- 能写出最小代码复现泛型擦除、HashMap key 变异、try-with-resources suppressed 异常和 ByteBuffer `flip` 错误。
- 能解释 String 常量池与拼接性能、注解的 Retention 与读取机制、虚拟线程的 pinning 与容量边界。
- 能把 Java 核心知识落到线上排查：慢接口看容器复杂度，内存涨看对象分配和集合持有，句柄泄漏看 `lsof` 与资源关闭。

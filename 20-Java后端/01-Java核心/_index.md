## 🧭 精通路线（按依赖学习）

1. **语言前置（05 → 06）**：先区分值和引用、类型转换与方法调用，避免把装箱、继承和泛型混在一起。
2. **类型与数据组织（01 → 02 → 03 → 04）**：泛型保证类型安全，异常明确失败边界，String 引出值语义，集合总纲再进入各实现与排序。
3. **对象与常用值（17 → 07 → 08）**：集合学完后看别名与可变元素，再补精确数值和时间模型，明确业务数据的含义。
4. **数据处理（09 ↔ 10）**：Optional 与 Lambda/Stream 连读，重点做 map/flatMap、重复键合并、可修改列表和惰性备用值实验。
5. **数据读写（11 → 18 → 19）**：先处理文件和字符集，再做对象 → JSON → 文件 → 对象的转换；原生对象流按需求深入。正则从校验、提取、替换和切分入手，日期和结构化格式交给对应解析器。
6. **运行期机制（12 → 13，20 选读）**：先理解反射、代理与注解。遇到模块化库或访问异常，再用 20 的两个模块实验理解可读、导出和深反射；不要求为学 Spring 先迁移 JPMS。SPI 复用 [[../02-JVM/05-类加载机制与双亲委派|JVM 类加载章节]]。
7. **现代建模与并发入口（14 → 15）**：Record 的防御性拷贝衔接 17；虚拟线程深入见 [[../03-并发编程/11-虚拟线程深入|虚拟线程深入]]。
8. **复习**：集合操作查 [[16-集合速查]]，按 [[99-本章总结与复习]] 做闭卷解释和实验。

## 🧪 验证目标

- 能复现 int 溢出、null 拆箱与“修改对象可见、形参重绑定不可见”。
- 能解释 emoji 的代码单元数、码点数、UTF-8 字节数为何不同。
- 能区分 BigDecimal.equals/compareTo，写出明确舍入的除法。
- 能用固定 Clock 验证日期逻辑，解释本地时间与瞬间、日历一天与 24 小时的差异。
- 能完成集合选型，解释扩容、拆链和不可修改容器的边界。
- 能验证 Optional 备用函数次数、重复键合并与文件资源关闭；能手写对象深拷贝，并完成对象与 JSON 文件的往返转换。
- 能验证两种枚举的 isSealed；模块选读时能运行跨模块调用，并复现缺少 requires / exports 和反射未开放的错误。
- 能回答各篇折叠面试题，并说明版本与适用边界。

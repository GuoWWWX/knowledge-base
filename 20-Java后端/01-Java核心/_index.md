# 📘 01 · Java 核心

> [!info] 本区说明
> 语言基础（泛型、异常）、集合框架、数据处理（Lambda/Stream）、IO/NIO、运行期机制（反射/动态代理）与现代 Java 新特性（Record/密封类/虚拟线程）。

## 📚 知识笔记清单（按学习顺序编号，顺着编号读即可）

- [ ] [[01-泛型与类型擦除]] — 类型系统地基：集合、Lambda、反射全都建立在泛型之上
- [ ] [[02-异常处理最佳实践]] — 错误处理地基：后续 IO 资源关闭、框架排查都依赖异常语义
- [ ] [[03-集合框架-List-Map-Set源码]] — 数据组织：List/Set/Map 的选型与源码
- [ ] [[04-HashMap原理与扩容]] — 数据组织深挖：哈希、冲突、扩容的完整原理
- [ ] [[05-Lambda与Stream]] — 数据处理：函数式接口、惰性流水线、并行边界
- [ ] [[06-IO与NIO]] — 数据移动：流、Buffer/Channel/Selector、零拷贝、句柄泄漏
- [ ] [[07-反射与动态代理]] — 运行期机制：框架（Spring AOP、RPC）的地基
- [ ] [[08-Java新特性-Record-密封类-虚拟线程]] — 现代语法收尾：Record/sealed 建模、虚拟线程入门

## 🧭 精通路线（为什么是这个顺序）

> 每一篇的“本节定位”小节都写了上一课衔接与延伸阅读，按编号顺序学即可，不用跳。

1. **先打地基（01→02）**：[[01-泛型与类型擦除]] 讲清类型系统如何工作（擦除、通配符、PECS），[[02-异常处理最佳实践]] 讲清错误如何分类与传播。后续所有章节都会用到这两个基础。
2. **再组织数据（03→04）**：[[03-集合框架-List-Map-Set源码]] 先建立 List/Set/Map 的整体选型观，[[04-HashMap原理与扩容]] 再深挖哈希表这一个最常用、面试最深的数据结构。
3. **处理与移动数据（05→06）**：[[05-Lambda与Stream]] 用声明式流水线处理集合，[[06-IO与NIO]] 处理文件与网络读写（try-with-resources 来自 02，Buffer 状态机是 NIO 核心）。
4. **理解运行期机制（07）**：[[07-反射与动态代理]] 解释框架如何在运行期检查、调用、增强对象——这是后面 Spring 章节的必备前置。
5. **现代语法收尾（08）**：[[08-Java新特性-Record-密封类-虚拟线程]] 是前面知识在工程建模上的应用收尾；虚拟线程部分只做入门，深入内容在 03-并发编程 章节。

## 🧪 验证目标

- 能从源码入口解释一次 `put/get/remove`、一次反射调用、一次 Stream 终端操作的真实执行路径。
- 能写出最小代码复现泛型擦除、HashMap key 变异、try-with-resources suppressed 异常和 ByteBuffer `flip` 错误。
- 能把 Java 核心知识落到线上排查：慢接口看容器复杂度，内存涨看对象分配和集合持有，句柄泄漏看 `lsof` 与资源关闭。

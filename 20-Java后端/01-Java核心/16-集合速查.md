# 一、家族结构速查

## 1.1 两棵家族树

```
Collection（单元素容器）
├── List（有序、可重复、按下标）
│   ├── ArrayList      —— 数组
│   └── LinkedList     —— 双向链表
├── Set（不重复）
│   ├── HashSet        —— 底层 HashMap
│   ├── LinkedHashSet  —— 底层 LinkedHashMap（保插入序）
│   └── TreeSet        —— 底层 TreeMap（按排序）
└── Queue/Deque（队列/双端）
    ├── ArrayDeque     —— 循环数组
    └── PriorityQueue  —— 二叉堆（按优先级）

Map（键值映射，不继承 Collection）
├── HashMap           —— 哈希表
├── LinkedHashMap     —— HashMap + 双向链表（保序/LRU）
└── TreeMap           —— 红黑树（按 key 排序）
```

## 1.2 三个必须记住的关系

| 关系 | 说明 |
| ---- | ---- |
| Set = 只用 key 的 Map | HashSet 组合 HashMap、TreeSet 组合 TreeMap、LinkedHashSet 组合 LinkedHashMap |
| Map 不继承 Collection | 但 `keySet()`/`values()`/`entrySet()` 返回 Collection |
| 遗留类 | `Vector`/`Stack`/`Hashtable`：全方法 synchronized，性能差，生产别用 |

# 二、各实现特性速查（核心表）

| 实现 | 底层 | 有序? | 允许 null | 复杂度要点 | 备注 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| **ArrayList** | 数组 | ✅ 按下标 | ✅ | get/set O(1)；尾增平均 O(1)；中间插删 O(n) | **List 默认首选** |
| **LinkedList** | 双向链表 | ✅ 按下标 | ✅ | 按下标 O(n)；头尾 O(1)；已持节点插删 O(1) | 节点开销 3 倍，少用 |
| **HashSet** | HashMap | ❌ | ✅（1 个 null） | add/remove/contains O(1) | **Set 默认首选** |
| **LinkedHashSet** | LinkedHashMap | ✅ 插入序 | ✅ | 同上 + 维护链表 | 保序去重 |
| **TreeSet** | TreeMap（红黑树） | ✅ 排序 | ❌ | 增删查 O(log n) | 元素需 Comparable/Comparator |
| **ArrayDeque** | 循环数组 | ✅ 头尾序 | ❌ | 头尾 O(1)；按下标 O(n) | **队列/栈默认首选** |
| **PriorityQueue** | 二叉堆 | ❌（出队按优先级） | ❌ | offer/poll O(log n)；peek O(1) | 迭代顺序 ≠ 出队顺序 |
| **HashMap** | 哈希表 | ❌ | ✅（1 个 null key） | get/put O(1) 平均；扩容重哈希 | **Map 默认首选** |
| **LinkedHashMap** | HashMap + 链表 | ✅ 插入序 / 访问序 | ✅ | 同上 + 维护链表 | 可做 LRU（accessOrder） |
| **TreeMap** | 红黑树 | ✅ 按 key 排序 | ❌ | O(log n) | 范围查询 subMap/headMap/tailMap |

> [!note] 一句话记默认
> **List 默认 ArrayList、Set 默认 HashSet、Map 默认 HashMap、队列/栈默认 ArrayDeque。** 其余是"有特殊需求才换"。

# 三、选型速查（什么场景用什么）

| 需求 | 选它 | 为什么 |
| ---- | ---- | ---- |
| 按下标读多、尾增 | ArrayList | get O(1)、缓存友好 |
| 头尾操作极多 | ArrayDeque | 头尾 O(1) 无节点开销 |
| 去重 | HashSet | add O(1) |
| 去重 + 保序 | LinkedHashSet | 哈希 + 链表 |
| 去重 + 排序 | TreeSet | 红黑树天然有序 |
| key → value | HashMap | 默认 |
| 保持插入顺序的 Map | LinkedHashMap | 双向链表 |
| LRU 缓存 | LinkedHashMap(accessOrder) | 访问序 + 重写 removeEldestEntry |
| 按 key 范围查询 | TreeMap | subMap/headMap/tailMap |
| FIFO 队列 | ArrayDeque | 头尾 O(1) |
| 按优先级出队 / TopK | PriorityQueue | 堆 |
| 频繁 contains 的 List 优化 | 换 HashSet | O(n) → O(1) |

# 四、常用操作速查

## 4.1 增删改查

| 操作 | 写法 |
| ---- | ---- |
| 建空集合 | `new ArrayList<>()` / `new HashMap<>()` |
| 建带初始容量 | `new ArrayList<>(1000)` / `new HashMap<>(预估/0.75f)` |
| 建不可变 | `List.of(...)` / `Set.of` / `Map.of`（null 会 NPE） |
| 从数组转 List | `Arrays.asList(arr)`（定长视图，不能增删，能 set） |
| List 转数组 | `list.toArray(new String[0])` |
| 尾增 | `list.add(x)`（平均 O(1)） |
| 按下标取 | `list.get(i)`（O(1)） |
| 判断存在 | `list.contains(x)` O(n) / `set.contains` O(1) |
| Map 取值带默认 | `map.getOrDefault(k, def)` |
| Map 没有才创建 | `map.computeIfAbsent(k, k -> new ArrayList<>())` |
| 排序 | `list.sort(Comparator.comparing(User::age))` |
| 复制成可变 | `new ArrayList<>(list)` |
| 复制成不可变 | `List.copyOf(list)`（null NPE） |

## 4.2 遍历与删除

| 场景 | 做法 |
| ---- | ---- |
| 遍历删（推荐） | `list.removeIf(pred)` |
| 迭代器删 | `it.remove()`（唯一"正道"） |
| 遍历时直接删 | ❌ `ConcurrentModificationException` |
| 逆序删 ArrayList | `for (i = size-1; i >= 0; i--)` 避免搬移 |
| 删 Map entry | `map.entrySet().removeIf(...)` |

## 4.3 去重

| 需求 | 做法 |
| ---- | ---- |
| 保序去重 | `list.stream().distinct().toList()` 或 `new LinkedHashSet<>(list)` |
| 不保序去重 | `new HashSet<>(list)` |
| 按字段去重 | `Collectors.toMap(取key, e->e, (a,b)->a, LinkedHashMap::new)` 的 values |

## 4.4 查找

| 需求 | 做法 | 复杂度 |
| ---- | ---- | ---- |
| 找下标 | `list.indexOf(x)` | O(n) |
| 排序数组二分 | `Arrays.binarySearch(arr, key)` | O(log n) |
| 取最大/最小 | `Collections.max/min(list)` | O(n) |
| 第 K 大 | PriorityQueue 堆 | O(n log K) |

# 六、易错点速查

## 6.1 十大坑

| 坑 | 后果 | 正确姿势 |
| ---- | ---- | ---- |
| 遍历中 `list.remove/add` | ConcurrentModificationException | `removeIf` / `it.remove()` |
| `subList` 返回后改原 list | 视图失效抛异常 | 别混着改；或复制 `new ArrayList<>(sub)` |
| `subList` 的修改 | 会串回原 list | 注意误伤 |
| `stream().toList()` 后 add | UnsupportedOperationException | 要可变用 `Collectors.toList()` |
| `Arrays.asList` 后 add/remove | UnsupportedOperationException | `new ArrayList<>(...)` |
| HashSet 元素改 hashCode 字段 | 元素永久丢失（查不到、删不掉） | key/元素不可变，或改前先删 |
| TreeSet/TreeMap 元素改排序字段 | 红黑树结构错乱 | 排序字段不可变 |
| 比较器 `a - b` | int 溢出 | `Integer.compare(a, b)` |
| Map 遍历时 put/remove | ConcurrentModificationException | `entrySet().removeIf` 或收集后删 |
| 多线程同时改非并发容器 | 数据错乱/异常 | 并发容器（见并发章节） |

## 6.2 两个易混异常

| 异常                                | 场景          | 一句话          |
| --------------------------------- | ----------- | ------------ |
| `ConcurrentModificationException` | 迭代中被结构修改    | "你在改时我还在遍历"  |
| `UnsupportedOperationException`   | 不可变/定长集合的增删 | "这个集合不允许这么改" |

## 6.3 null 速查

| 集合 | 允许 null? |
| ---- | ---- |
| ArrayList / LinkedList | ✅ 任意个 |
| HashSet / LinkedHashSet | ✅ 1 个（HashMap 的 null key） |
| TreeSet / TreeMap | ❌（需要比较） |
| HashMap / LinkedHashMap | ✅ 1 个 null key + 多个 null value |
| ArrayDeque / PriorityQueue | ❌（ArrayDeque 用 null 判空位；堆要比较） |
| `List.of` / `Set.of` / `Map.of` | ❌（直接 NPE） |
| `Arrays.asList` | ✅ 允许 |

# 七、面试速记

> [!question] 高频问题
> - **Q: 各集合默认选什么？**
>   - A: List→ArrayList、Set→HashSet、Map→HashMap、队列/栈→ArrayDeque。有特殊需求（保序/排序/优先级/LRU）才换对应的 Linked/Tree/Priority 变体。
> - **Q: HashSet 和 TreeSet 区别？**
>   - A: HashSet 哈希表 O(1)、无序、允许 1 个 null；TreeSet 红黑树 O(log n)、按排序、不允许 null、元素要可比。
> - **Q: LinkedHashMap 怎么实现 LRU？**
>   - A: accessOrder=true 时每次 get 把节点移到链表尾，重写 `removeEldestEntry` 在容量超限时删除链表头。
> - **Q: PriorityQueue 迭代顺序是出队顺序吗？**
>   - A: 不是。迭代是堆数组序，要按优先级取只能 poll。
> - **Q: 为什么增强 for 里不能 remove？**
>   - A: 迭代器快照 expectedModCount，结构修改让 modCount++，next() 发现不一致抛 ConcurrentModificationException。用 `it.remove()` / `removeIf`。

# 八、口诀

> **List 默认 ArrayList，Set 默认 HashSet，Map 默认 HashMap，队列栈用 ArrayDeque；**
> **保序用 Linked，排序用 Tree，优先级用 Priority，LRU 用 LinkedHashMap；**
> **遍历删除 removeIf，迭代删除 it.remove；**
> **不可变 List.of / toList，可变才 collect；**
> **key 和元素别改哈希/排序字段；**
> **List.contains 频繁就换 HashSet。**

# 05 · 数据库与存储

> [!info] 本区说明
> 数据库学习主线是：数据如何组织，查询如何执行，并发如何控制，缓存如何保护存储，扩容后如何保持可用和一致。

## 🧭 学习路径

- MySQL 先掌握 B+ 树、执行计划、事务 MVCC 和锁。
- Redis 先掌握数据结构、过期淘汰、持久化，再看缓存异常和架构。
- 分库分表放在最后，先确认单库优化已经到边界。

## ✅ 验收标准

- 能根据 SQL 设计联合索引并用 EXPLAIN ANALYZE 验证。
- 能从锁等待日志定位阻塞事务和锁范围。
- 能设计 cache-aside 的读写路径、TTL、击穿保护和一致性补偿。

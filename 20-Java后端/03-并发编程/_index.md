# 🔀 03 · 并发编程（从零到精通实战指南）

> [!tip] 学习心法
> **并发编程的本质是“在追求极致性能的同时，守住数据安全的底线”。**
> 本模块立足于第一性原理，采用 **【核心机制原理 + 源码与底层实现 + 生产实战与避坑指南】** 的结构化模型编写。示例以 **Java 21 LTS** 为基线。

## 💻 怎样运行文中的示例？

- 文中所有带 `public class` 的示例均可以直接复制，存为同名 `.java` 文件，在安装了 JDK 21+ 的终端中执行 `java 文件名.java` 即可直接观察结果。
- 每个案例均提供“**翻车现场代码**”与“**加锁修复后代码**”，建议亲手运行对比输出差异。

# 📖 个人学习知识库 · 总说明与通用规范

> [!info] 这是什么
> 这是一个基于 Obsidian 的个人学习知识库，覆盖 **三大学习领域**：AI 应用开发、Java 后端、算法与数据结构。
> 本 README 是 **根级总说明 + 通用规范**。每个领域还有自己的领域规范（各自的 README）。

---

## 🚀 从哪开始

1. 打开 [[00-总览/总仪表盘]] —— 整个知识库的最高入口（建议设为 Obsidian 首页）
2. 进入某个领域的仪表盘开始学习
3. 学到知识 → 记到对应领域的对应知识区
4. 每周在 `50-学习日志/` 写一篇综合日志

## 🏷️ 通用规范（三领域都适用）

### 1. 命名规范

> [!important] 命名三原则
> 1. **不用空格**，用连字符 `-` 分隔
> 2. **见名知意**，中文名 + 必要英文术语
> 3. **同类文件加统一前缀**

| 文件类型 | 命名格式 | 示例 |
| -------- | -------- | ---- |
| 区索引 | `_index.md` | 固定，排最前 |
| 知识笔记 | `<序号>-<主题>.md` | `05-HashMap原理与扩容.md` |
| 项目文档 | `<序号>-项目-<名>.md` | `03-项目-企业知识库RAG系统.md` |
| 算法题解 | `<序号>-LC<题号>-<题名>.md` | `01-LC0001-两数之和.md` |
| 周日志 | `周日志-<年>-W<周>.md` | `周日志-2026-W23.md` |
| 面试题 | `<序号>-面试-<主题>.md` | `09-面试-JVM.md` |

> 知识目录内按 `_index.md` 的推荐学习顺序从 `01` 连续编号；`_index.md`、README 和总览文件不参与编号，章节总结使用 `99-` 前缀。

### 2. Frontmatter（YAML 头）规范

每篇文档都要有，**第一个标签必须是 `领域/xxx`**：

```yaml
---
title: 笔记标题
tags:
  - 领域/Java后端      # 领域：AI应用 / Java后端 / 算法
  - 类型/知识          # 类型：知识 / 项目 / 题解 / 日志 / 面试 / 索引 / 总览
  - 主题/JVM           # 主题：领域内细分
created: 2026-05-31
updated: 2026-05-31
status: 草稿          # 草稿 / 整理中 / 已完成
mastery: ⭐⭐☆☆☆      # 掌握程度
---
```

> [!tip] 标签层级体系
> 用「分类/值」写法，在 Obsidian 标签面板可折叠筛选：
> - `领域/AI应用`、`领域/Java后端`、`领域/算法`
> - `类型/知识`、`类型/题解`、`类型/面试` …
> - `主题/RAG`、`主题/JVM`、`算法/DP` …

### 3. 双向链接规范

- 知识点之间相关概念互相用 Obsidian 双链，例如指向实际存在的笔记
- 跨领域可互链（如 Java 并发 ↔ AI 工程化）
- 每篇笔记底部链回所在区 `_index`
- 引用章节时使用实际文档名和章节名，例如 `[[05-HashMap原理与扩容#扩容流程]]`

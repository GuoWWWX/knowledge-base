# 🧠 学习方法与复习系统 · 怎么用这个库真正学会并记牢

> [!abstract] 一句话总结
> 这个库的文档只是"弹药库"，真正让你学会的是三个动作：**主动回忆（自测）、间隔重复（按日期回来复习）、费曼输出（讲给别人听）**。本文规定这三个动作在本库中怎么落地。

> [!warning] 为什么需要这篇文档
> 目前库里 341 篇文档大多 status 已完成，但 mastery 几乎全是 ⭐1、学习日志 8 周零记录——**"文档写完了" ≠ "学会了"**。看懂一篇笔记时的"我懂了"感觉，3 天后会消失 70%。这篇文档就是防止"收藏 = 学会"错觉的操作手册。

---

## 一、三个底层原理（为什么这么设计）

| 原理 | 一句话 | 反面教材 |
| ---- | ---- | ---- |
| **主动回忆** | 想答案比看答案有效 5 倍以上 | 反复重读笔记、划重点（流畅感 ≠ 记住） |
| **间隔重复** | 快忘时复习一次，记忆保持时间翻倍 | 学完当天猛复习 3 遍，之后再也不碰 |
| **费曼输出** | 讲不出来 = 没学会，卡壳处就是漏洞 | "我看懂了"（其实只是认得每个字） |

---

## 二、一篇新笔记的标准学法（约 30~45 分钟/篇）

按新版 [[../99-模板/知识笔记模板|知识笔记模板]] 的区块顺序：

1. **只读"一句话总结 + 白话版"**，合上文档，用自己的话说一遍这是什么 → 说不出来再读一遍
2. **读"解决什么问题"**：记住"没有它会发生什么坏事"——这是记忆的挂钩
3. **读"工作原理"时跟着例子在纸上/脑内走一遍流程**，每步问自己"为什么是这样"
4. **做"最小验证"**：10 分钟动手实验。做过一遍的知识和只看过的知识不是同一种记忆
5. **做"自测题"**：先口头回答，再展开折叠对答案
6. **收尾三件事**：
   - 给 frontmatter 打真实的 `mastery`（自测全对 ⭐⭐⭐，有卡壳 ⭐⭐，基本答不上 ⭐）
   - 填 `next_review`（规则见下表）
   - 用一句话把这篇讲给"想象中的同事"听（费曼 30 秒版）

> [!tip] 老文档没有"白话版/自测题"怎么办
> 旧模板的文档（大部分 2026-07-04 生成的）缺这些区块。**复习到哪篇，就顺手让 Claude 按新模板升级哪篇**——不要试图一次性全部升级，跟着复习节奏来。

## 三、复习排程规则（间隔重复）

复习动作 = **只做该篇的"自测题"和"面试问题"，不重读正文**。答对了才允许升星。

| 当前 mastery | 自测结果 | 新 mastery | 下次复习（next_review） |
| ---- | ---- | ---- | ---- |
| ⭐ | 基本答不上 | ⭐ | +2 天 |
| ⭐ | 大部分答对 | ⭐⭐ | +4 天 |
| ⭐⭐ | 答对 | ⭐⭐⭐ | +7 天 |
| ⭐⭐⭐ | 答对 | ⭐⭐⭐⭐ | +14 天 |
| ⭐⭐⭐⭐ | 答对 | ⭐⭐⭐⭐⭐ | +30 天 |
| ⭐⭐⭐⭐⭐ | 答对 | ⭐⭐⭐⭐⭐ | +60 天 |
| 任意 | 有明显卡壳 | **降一星** | +2 天 |

> [!important] 两条铁律
> 1. **升星只能靠自测，不能靠"感觉熟了"**
> 2. 复习完必须更新 frontmatter 的 `mastery` 和 `next_review` 两个字段——这是整个系统的发动机

## 四、今日复习队列（Dataview 自动生成）

把下面的查询放在仪表盘或每天打开这页看。**需要先安装 Dataview 插件**（README 推荐插件清单里有）。

### 4.1 今天该复习的笔记（每天先清这个队列）

```dataview
TABLE mastery AS 掌握度, next_review AS 复习日
FROM "10-AI应用开发" OR "20-Java后端" OR "30-算法与数据结构"
WHERE next_review AND date(next_review) <= date(today)
SORT next_review ASC
LIMIT 15
```

### 4.2 还没进入复习循环的"已完成"文档（最危险的一批）

标着"已完成"却从没自测过的文档，是最容易产生"我已经会了"错觉的地方。每周挑几篇补 `next_review`，让它们进入循环。

```dataview
TABLE mastery AS 掌握度, file.folder AS 所在章节
FROM "10-AI应用开发" OR "20-Java后端"
WHERE status = "已完成" AND !next_review AND !contains(file.name, "_index") AND !contains(file.name, "99-")
SORT file.path ASC
LIMIT 20
```

### 4.3 掌握度分布（每周看一眼趋势）

理想曲线：⭐1 的数量每周下降，⭐3 以上每周上升。

```dataview
TABLE length(rows) AS 篇数
FROM "10-AI应用开发" OR "20-Java后端" OR "30-算法与数据结构"
WHERE mastery
GROUP BY mastery AS 掌握度
SORT 掌握度 DESC
```

### 4.4 逾期最久的（欠债清单）

```dataview
TABLE mastery AS 掌握度, next_review AS 原定复习日,
      (date(today) - date(next_review)).days AS 逾期天数
FROM "10-AI应用开发" OR "20-Java后端" OR "30-算法与数据结构"
WHERE next_review AND date(next_review) < date(today) - dur(3 days)
SORT next_review ASC
LIMIT 10
```

> [!tip] 不想装插件的极简替代
> 用 Obsidian 自带搜索框输入 `next_review:2026-07-29`（或当天日期）也能凑合筛出来，只是不能自动排序。

## 五、每日 / 每周节奏

### 每日（工作日约 1.5~2 小时）

| 时段 | 时长 | 动作 |
| ---- | ---- | ---- |
| 开场 | 15~20 分钟 | 清"今日复习队列"（做自测题 → 更新星级和日期） |
| 主体 | 60~90 分钟 | 学 1~2 篇新笔记（按第二节的标准学法）或推进项目实战 |
| 收尾 | 5 分钟 | 在周日志草稿里记一行：今天学了什么、哪里卡壳 |

### 每周日（30 分钟）

1. 用 [[../99-模板/周学习日志模板]] 写周日志（**这个动作 8 周没发生过了，从本周开始**）
2. 看 4.3 的掌握度统计：⭐⭐⭐ 以上的比例有没有涨
3. 挑 1 篇本周学的知识，做一次完整费曼：不看笔记写 200 字讲解，写不出来的地方回去补

## 六、费曼技巧的三个落地形态（从轻到重）

1. **30 秒口述**：每学完一篇，对着空气把"一句话总结 + 为什么需要它"讲一遍
2. **面试模拟**：把该篇"面试问题"当真实面试答，先 30 秒结论版，再 2 分钟展开版
3. **让 Claude 当面试官**：把笔记标题发给 Claude："针对 XX 主题连续追问我 5 个问题，每次根据我的回答追问更深一层，最后指出我答错和答浅的地方"——这是性价比最高的自测方式

## 七、用 AI 加速学习的正确姿势

| 场景 | 提示词模板 |
| ---- | ---- |
| 看不懂某段 | "用一个生活类比解释 XX，然后再用技术语言讲一遍，最后指出类比在哪里失效" |
| 怀疑自己没懂 | "我用自己的话讲一遍 XX：……。请指出我理解错误或遗漏的地方" |
| 复习出题 | "针对 XX 出 5 道由浅入深的问题，先别给答案，等我答完再逐题点评" |
| 升级旧笔记 | "按 99-模板/知识笔记模板 的结构升级这篇笔记，重点补白话版、从坏到好案例、自测题" |
| 面试冲刺 | "你是面试官，就 XX 主题面我 10 分钟，从基础问到原理再到项目场景，我答完后给我评分和改进建议" |

> [!warning] 一个反模式
> 不要让 AI"帮我总结这篇笔记"然后只读总结——那是把主动回忆的机会外包出去了。AI 用来**出题、纠错、换角度解释**，不用来替你回忆。

## 八、优先级：先把哪些学"牢"

面试视角下不是 341 篇平权。建议的精力分配：

1. **第一优先**（必须 ⭐⭐⭐⭐ 以上）：RAG 全链路、Agent/MCP、多轮对话记忆、Java 并发、JVM、MySQL/Redis —— 对应 [[../40-求职准备/_index|求职准备]] 里的高频面试主题
2. **第二优先**（⭐⭐⭐ 即可）：Spring AI 框架细节、平台工程化、分布式
3. **第三优先**（能查到就行，不背）：各平台入门（Dify/Coze/百炼）、辅助语言速查

配套动作：**项目实战 > 笔记复习**。同一知识点，在 [[../10-AI应用开发/08-项目实战/_index|项目]] 里用过一次抵得上复习三次——复习队列里反复卡壳的知识点，优先安排进项目里用一遍。

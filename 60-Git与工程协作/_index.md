# Git 与工程协作

> [!info] 本区说明
> 这是 AI、Java 和算法项目共用的工程基础区。内容从首次拉取代码开始，覆盖日常提交、分支协作、发布打标、线上回滚和误操作恢复。

- [x] [[01-Git全流程实战手册]]：完整生命周期总览，适合先通读和查流程

## 学完应能做到

- 能解释工作区、暂存区、本地仓库和远程仓库之间的数据流动。
- 能独立完成“拉分支 -> 开发 -> 提交 -> 同步主干 -> 推送 -> 提 MR/PR”。
- 能判断何时使用 merge、rebase、revert、reset 和 restore。
- 能在不改写公共历史的前提下完成发布、回滚和误操作恢复。
- 能通过 `status`、`log`、`diff` 和远端引用验证操作结果，而不是只看命令是否报错。

# LC0560-和为K的子数组

> 链接：[LeetCode 560](https://leetcode.cn/problems/subarray-sum-equals-k/)

## 🧾 题目理解

给定整数数组和整数 `k`，统计和为 `k` 的连续子数组个数。数组中可能有负数。

## 💡 思路

设当前位置前缀和为 `prefix`。如果之前出现过前缀和 `prefix - k`，那么这些位置之后到当前位置的子数组和就是 `k`。用哈希表统计每个前缀和出现次数，边扫描边累加答案。

初始化 `map[0] = 1`，用于统计从数组开头开始的子数组。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);
        int prefix = 0;
        int ans = 0;
        for (int num : nums) {
            prefix += num;
            ans += count.getOrDefault(prefix - k, 0);
            count.put(prefix, count.getOrDefault(prefix, 0) + 1);
        }
        return ans;
    }
}
```

## ⚠️ 易错点

- 因为有负数，不能用普通滑动窗口。
- 先查询 `prefix - k`，再把当前 `prefix` 计入哈希表。
- `map[0] = 1` 不能漏，否则从下标 0 开始的答案会少算。

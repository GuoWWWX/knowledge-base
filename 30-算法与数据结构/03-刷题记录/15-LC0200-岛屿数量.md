# LC0200-岛屿数量

> 链接：[LeetCode 200](https://leetcode.cn/problems/number-of-islands/)

## 🧾 题目理解

给定由 `'1'` 和 `'0'` 组成的网格，统计四方向相连的陆地连通块数量。

## 💡 思路

遍历每个格子，遇到未访问的陆地就把岛屿数加一，并从该格子开始 DFS，把同一个连通块内的陆地全部标记为水。这样每块岛只会被计数一次。

## ⏱️ 复杂度

- 时间复杂度：`O(mn)`。
- 空间复杂度：`O(mn)`，最坏情况下递归栈覆盖整个网格。

## 💻 Java 代码

```java
class Solution {
    public int numIslands(char[][] grid) {
        int ans = 0;
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[0].length; c++) {
                if (grid[r][c] == '1') {
                    ans++;
                    dfs(grid, r, c);
                }
            }
        }
        return ans;
    }

    private void dfs(char[][] grid, int r, int c) {
        if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] != '1') {
            return;
        }
        grid[r][c] = '0';
        dfs(grid, r + 1, c);
        dfs(grid, r - 1, c);
        dfs(grid, r, c + 1);
        dfs(grid, r, c - 1);
    }
}
```

## ⚠️ 易错点

- 只计算上下左右相连，斜方向不算。
- 访问过的陆地必须标记，否则会重复计数或死递归。
- Java 递归在极大网格上可能栈溢出，可改 BFS。

# LC0046-全排列

> 链接：[LeetCode 46](https://leetcode.cn/problems/permutations/)

## 🧾 题目理解

给定不含重复数字的数组，返回所有可能的排列。

## 💡 思路

回溯维护当前路径 `path` 和使用标记 `used`。每一层枚举一个尚未使用的数字加入路径，递归结束后撤销选择，恢复现场。

## ⏱️ 复杂度

- 时间复杂度：`O(n * n!)`，每个排列复制一次。
- 空间复杂度：`O(n)`，不计答案数组。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        backtrack(nums, used, new ArrayList<>(), ans);
        return ans;
    }

    private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> ans) {
        if (path.size() == nums.length) {
            ans.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.add(nums[i]);
            backtrack(nums, used, path, ans);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

## ⚠️ 易错点

- 加入答案时必须复制 `path`。
- 撤销选择要同时恢复 `path` 和 `used`。
- 本题无重复数字；有重复数字时需要排序并做同层去重。

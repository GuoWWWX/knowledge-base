# LC0215-数组中的第K个最大元素

> 链接：[LeetCode 215](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

## 🧾 题目理解

给定整数数组和整数 `k`，返回数组中第 `k` 个最大的元素，不是第 `k` 个不同元素。

## 💡 思路

用容量为 `k` 的小根堆保存当前见过的 `k` 个最大值。遍历数组时入堆，若堆大小超过 `k` 就弹出最小值；遍历结束后堆顶就是第 `k` 大。

## ⏱️ 复杂度

- 时间复杂度：`O(n log k)`。
- 空间复杂度：`O(k)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int num : nums) {
            heap.offer(num);
            if (heap.size() > k) {
                heap.poll();
            }
        }
        return heap.peek();
    }
}
```

## ⚠️ 易错点

- 第 `k` 大不是去重后的第 `k` 大。
- 小根堆容量保持为 `k`，不是 `n - k + 1`。
- 若追求平均 `O(n)`，可改快速选择。

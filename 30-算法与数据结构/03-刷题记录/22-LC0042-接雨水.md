# LC0042-接雨水

> 链接：[LeetCode 42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)

## 🧾 题目理解

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

- **输入**：`height = [0,1,0,2,1,0,1,3,2,1,2,1]`
- **输出**：`6`
- **解释**：由数组 `[0,1,0,2,1,0,1,3,2,1,2,1]` 表示的雨水高度梯形中，共积水 6 个单位。

---

## 💡 思路

### 解法一：对撞双指针（最优解，空间 $O(1)$）
每个位置 $i$ 能接的雨水量，取决于其左右两边最高柱子的**较小值**（短板理论）：
$$\text{water}[i] = \max(0, \min(\text{leftMax}, \text{rightMax}) - \text{height}[i])$$

使用左右双指针 `left = 0, right = n - 1` 向中间收缩：
- 维护 `leftMax` 和 `rightMax`；
- 若 `leftMax < rightMax`，说明对于当前 `left` 而言，左边的短板已经确定为 `leftMax`（右边肯定有至少为 `rightMax` 的更高柱子挡着），直接结算当前位置积水并 `left++`；
- 反之若 `leftMax >= rightMax`，说明右边是短板，结算右侧并 `right--`。

---

## ⏱️ 复杂度

- 时间复杂度：$O(n)$，左右指针仅遍历一次数组。
- 空间复杂度：$O(1)$，仅常数额外指针变量。

---

## 💻 Java 代码

```java
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length < 3) return 0;

        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int totalWater = 0;

        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            // 短板在左侧，结算左指针
            if (leftMax < rightMax) {
                totalWater += leftMax - height[left];
                left++;
            } else {
                // 短板在右侧，结算右指针
                totalWater += rightMax - height[right];
                right--;
            }
        }
        return totalWater;
    }
}
```

---

## ⚠️ 易错点

- **不要混淆“按列求积水”与“按行求积水”**：双指针法是按列结算当前位置的竖直水量；单调栈法是按凹槽水平横向结算水量。
- 只有两端较小的那一侧柱子水量能够被绝对断定，切忌在 `leftMax < rightMax` 时去结算 `right` 指针。

# LC0094-二叉树中序遍历

> 链接：[LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

## 🧾 题目理解

返回二叉树的中序遍历结果，即左子树、根节点、右子树。

## 💡 思路

递归写法直接按“左、根、右”访问。迭代写法用栈不断压入左链，弹出节点后访问，再转向右子树。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`，`h` 为树高，最坏 `O(n)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            ans.add(cur.val);
            cur = cur.right;
        }
        return ans;
    }
}
```

## ⚠️ 易错点

- 外层循环条件要包含 `cur != null || !stack.isEmpty()`。
- 弹出节点后再访问根节点。
- 空树应返回空列表。

# LC0300-最长递增子序列

> 链接：[LeetCode 300](https://leetcode.cn/problems/longest-increasing-subsequence/)

## 🧾 题目理解

给定整数数组，返回最长严格递增子序列的长度。子序列可以不连续，但相对顺序不能变。

## 💡 思路

维护 `tails[len]`：长度为 `len + 1` 的递增子序列的最小可能结尾。遍历每个数，用二分找到第一个 `>= num` 的位置并替换；如果位置等于当前长度，说明可以扩展出更长序列。

## ⏱️ 复杂度

- 时间复杂度：`O(n log n)`。
- 空间复杂度：`O(n)`。

## 💻 Java 代码

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int num : nums) {
            int left = 0, right = size;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < num) left = mid + 1;
                else right = mid;
            }
            tails[left] = num;
            if (left == size) size++;
        }
        return size;
    }
}
```

## ⚠️ 易错点

- 严格递增要找第一个 `>= num` 的位置；非严格递增才会用 `> num`。
- `tails` 不一定是真实 LIS，只保证长度正确。
- 子序列不是子数组，不要求连续。

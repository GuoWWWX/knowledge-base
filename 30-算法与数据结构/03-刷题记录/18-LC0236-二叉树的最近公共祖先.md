# LC0236-二叉树的最近公共祖先

> 链接：[LeetCode 236](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

## 🧾 题目理解

给定二叉树中两个节点 `p` 和 `q`，返回它们的最近公共祖先。

## 💡 思路

递归函数返回当前子树中是否找到 `p` 或 `q`。如果当前节点为空、等于 `p` 或等于 `q`，直接返回当前节点。递归查左右子树：左右都非空时当前节点就是 LCA；只有一侧非空时向上返回那一侧。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(h)`，`h` 为树高。

## 💻 Java 代码

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left != null && right != null) return root;
        return left != null ? left : right;
    }
}
```

## ⚠️ 易错点

- 比较节点引用，不是比较节点值。
- 如果左右子树分别命中，当前节点才是最近公共祖先。
- 本题默认 `p` 和 `q` 都存在于树中。

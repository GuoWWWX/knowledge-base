# LC0053-最大子数组和

> 链接：[LeetCode 53](https://leetcode.cn/problems/maximum-subarray/)

## 🧾 题目理解

给定整数数组，找出一个连续子数组，使其和最大，返回最大和。

## 💡 思路

令 `cur` 表示“必须以当前位置结尾”的最大子数组和。对每个数 `x`，要么接在之前子数组后面，要么从 `x` 重新开始：`cur = max(x, cur + x)`。答案维护所有 `cur` 的最大值。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int cur = nums[0], ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            cur = Math.max(nums[i], cur + nums[i]);
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## ⚠️ 易错点

- 答案要初始化为 `nums[0]`，不能初始化为 `0`，否则全负数组会错。
- 子数组必须连续。
- `cur` 的含义是“以当前元素结尾”，不是全局最大。

# LC0020-有效的括号

> 链接：[LeetCode 20](https://leetcode.cn/problems/valid-parentheses/)

## 🧾 题目理解

判断只包含括号字符的字符串是否有效：左括号必须由同类型右括号闭合，并且闭合顺序正确。

## 💡 思路

遇到左括号就把对应的右括号压栈；遇到右括号时，必须与栈顶期待值相等。这样栈里保存的是“未来必须出现的闭合符号”。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            else if (stack.isEmpty() || stack.pop() != c) return false;
        }
        return stack.isEmpty();
    }
}
```

## ⚠️ 易错点

- 右括号出现时栈可能为空。
- 遍历结束后栈必须为空，否则还有未闭合左括号。
- 用 `ArrayDeque` 作为栈，避免旧的 `Stack`。

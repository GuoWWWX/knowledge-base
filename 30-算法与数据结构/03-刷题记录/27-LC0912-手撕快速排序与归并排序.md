# LC0912-手撕快速排序与归并排序

> 链接：[LeetCode 912. 排序数组](https://leetcode.cn/problems/sort-an-array/)  
> **大厂考情**：字节跳动、阿里巴巴、腾讯、美团技术一面手撕算法 No.1 梯队。

## 🧾 题目理解

给你一个整数数组 `nums`，请你将该数组升序排列。

要求：不使用任何内置的排序函数（如 `Arrays.sort()`），**在 $O(N \log N)$ 的时间复杂度下纯手工手撕排序算法**。

### 输入输出示例
- **输入**：`nums = [5,2,3,1]` $\to$ **输出**：`[1,2,3,5]`
- **输入**：`nums = [5,1,1,2,0,0]` $\to$ **输出**：`[0,0,1,1,2,5]`

---

## 💡 手撕方案一：快速排序（QuickSort / 随机化双指针 Partition）

### 核心心智模型
1. **基准值选取（Pivot）**：若固定选左端点，在遭遇“逆序或完全有序”用例时，递归树退化为倾斜链表，复杂度恶化为 $O(N^2)$ 直接超时！**必须使用随机化基准值**；
2. **对撞双指针切分（Partition）**：
   - 选取随机基准值并移到最左侧；
   - 左右对撞指针扫描：左指针找首个大于基准值的，右指针找首个小于基准值的，交换并向内推进；
3. **分治递归**：基准值归位后，递归处理左右子区间。

```java
import java.util.Random;

class SolutionQuickSort {
    private static final Random RAND = new Random();

    public int[] sortArray(int[] nums) {
        if (nums == null || nums.length <= 1) return nums;
        quickSort(nums, 0, nums.length - 1);
        return nums;
    }

    private void quickSort(int[] nums, int left, int right) {
        if (left >= right) return;

        // 1. 随机选取 pivot 交换到区间最左侧，防止最坏退化
        int pivotIndex = left + RAND.nextInt(right - left + 1);
        swap(nums, left, pivotIndex);
        int pivot = nums[left];

        // 2. 双指针双向扫描
        int i = left + 1, j = right;
        while (true) {
            while (i <= j && nums[i] < pivot) i++;
            while (i <= j && nums[j] > pivot) j--;
            if (i >= j) break;
            swap(nums, i, j);
            i++;
            j--;
        }

        // 3. 将 pivot 放到正确的中界位置 j
        swap(nums, left, j);

        // 4. 递归处理左右子数组
        quickSort(nums, left, j - 1);
        quickSort(nums, j + 1, right);
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

## 💡 手撕方案二：归并排序（MergeSort / 稳定且性能最均衡）

### 核心心智模型
归并排序是纯粹的**分治法（Divide and Conquer）**：
1. **分（Divide）**：取中点 `mid = left + (right - left) / 2`，无条件向下一分为二，递归切分至单元素；
2. **治（Conquer）**：双指针合并两个有序子数组 `[left, mid]` 与 `[mid + 1, right]` 到临时数组 `temp` 中；
3. **回填**：将排好序的 `temp` 数组拷贝回原数组对应区间。

```java
class SolutionMergeSort {
    public int[] sortArray(int[] nums) {
        if (nums == null || nums.length <= 1) return nums;
        // 预分配辅助数组，避免递归内频繁 new 数组引起 GC 抖动
        int[] temp = new int[nums.length];
        mergeSort(nums, 0, nums.length - 1, temp);
        return nums;
    }

    private void mergeSort(int[] nums, int left, int right, int[] temp) {
        if (left >= right) return;

        int mid = left + (right - left) / 2;
        mergeSort(nums, left, mid, temp);
        mergeSort(nums, mid + 1, right, temp);

        // 优化剪枝：如果左半段最大值 <= 右半段最小值，说明已经整体有序，直接返回！
        if (nums[mid] <= nums[mid + 1]) return;

        merge(nums, left, mid, right, temp);
    }

    private void merge(int[] nums, int left, int mid, int right, int[] temp) {
        int i = left, j = mid + 1, k = left;

        // 双指针合并两段有序子序列
        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) {
                temp[k++] = nums[i++];
            } else {
                temp[k++] = nums[j++];
            }
        }
        // 处理剩余元素
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];

        // 拷贝回原数组
        for (int p = left; p <= right; p++) {
            nums[p] = temp[p];
        }
    }
}
```

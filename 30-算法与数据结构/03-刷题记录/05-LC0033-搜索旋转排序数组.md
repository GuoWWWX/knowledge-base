# LC0033-搜索旋转排序数组

> 链接：[LeetCode 33](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

## 🧾 题目理解

在无重复元素的旋转升序数组中查找 `target`，找到返回下标，否则返回 `-1`。

## 💡 思路

旋转数组虽然整体无序，但任意一次二分后，左右两半至少有一半是有序的。先判断哪一半有序，再看 `target` 是否落在有序半区内，决定保留哪一边。

## ⏱️ 复杂度

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;

            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

## ⚠️ 易错点

- 判断有序半区时边界要用 `<=`，覆盖单元素半区。
- 区间比较要一边闭一边开，避免把 `mid` 重复纳入。
- 本题无重复元素；有重复时判断逻辑要额外收缩边界。

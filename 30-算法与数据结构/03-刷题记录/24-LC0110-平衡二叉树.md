# LC0110-平衡二叉树

> 链接：[LeetCode 110. 平衡二叉树](https://leetcode.cn/problems/balanced-binary-tree/)  
> **大厂考情**：Shopee（虾皮）、字节跳动、腾讯等技术面试高频手撕原题。

## 🧾 题目理解

给定一个二叉树，判断它是否是高度平衡的二叉树。

本题中，一棵高度平衡二叉树定义为：**一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1**。

- **示例 1**：
  - 输入：`root = [3,9,20,null,null,15,7]`
  - 输出：`true`
- **示例 2**：
  - 输入：`root = [1,2,2,3,3,null,null,4,4]`
  - 输出：`false`
- **示例 3**：
  - 输入：`root = []`
  - 输出：`true`

---

## 💡 思路分析

### ❌ 暴力解法：自顶向下（面试踩坑写法，$O(N^2)$）
先写一个 `maxDepth(node)` 函数求深度，然后在根节点判断 `Math.abs(left - right) <= 1`，再递归判断 `isBalanced(root.left)` 和 `isBalanced(root.right)`。
- **缺点**：每个节点的高度被其上方所有祖先节点重复计算，在退化为链表时时间复杂度暴增为 $O(N^2)$，面试官会立即要求优化！

### ✅ 最优解法：自底向上后序遍历（$O(N)$ 提前剪枝）
类似于**后序遍历（左右根）**：
1. 递归从叶子节点往上返回高度；
2. 一旦在某个子树发现其左右子树高度差 $> 1$，说明该子树已经不平衡，**立即向上返回 `-1` 作为异常标记**；
3. 上层节点一旦收到左子树或右子树返回的 `-1`，**无需继续计算高度，直接短路向上传递 `-1`**！
4. 最终只需判断根节点的返回值是否 $\ne -1$。

---

## ⏱️ 复杂度

- **时间复杂度**：$O(N)$。每个节点仅被访问一次，短路剪枝极大减少递归次数。
- **空间复杂度**：$O(H)$（$H$ 为树的高度，平均 $O(\log N)$，最坏退化链表 $O(N)$ 为递归栈空间）。

## 💻 Java 标准可运行代码

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        return checkHeight(root) != -1;
    }

    /**
     * 计算节点高度；若发现已不平衡，则直接返回 -1 剪枝短路
     */
    private int checkHeight(TreeNode node) {
        if (node == null) return 0;

        // 1. 递归计算左子树高度
        int leftH = checkHeight(node.left);
        if (leftH == -1) return -1; // 左子树已不平衡，提前剪枝

        // 2. 递归计算右子树高度
        int rightH = checkHeight(node.right);
        if (rightH == -1) return -1; // 右子树已不平衡，提前剪枝

        // 3. 校验当前节点高度差
        if (Math.abs(leftH - rightH) > 1) {
            return -1; // 左右高度差大于 1，标记为不平衡
        }

        // 4. 返回当前子树的真实高度
        return Math.max(leftH, rightH) + 1;
    }
}
```

---

## ⚠️ 易错点

- 很多同学递归出口只写了 `if (node == null) return 0;`，漏掉了 `if (leftH == -1) return -1;` 的提前短路逻辑，导致无法做到真正线性。
- 绝不要在计算深度的过程中频繁去调外部公共求深函数。

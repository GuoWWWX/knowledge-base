# LC0206-反转链表

> 链接：[LeetCode 206](https://leetcode.cn/problems/reverse-linked-list/)

## 🧾 题目理解

反转单链表，并返回新的头节点。

## 💡 思路

用 `prev` 表示已经反转好的前缀头，`cur` 表示当前待处理节点。每次先保存 `cur.next`，再把 `cur.next` 指向 `prev`，最后整体向前推进。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

## ⚠️ 易错点

- 改指针前必须保存 `next`。
- 最终返回 `prev`，不是原 `head`。
- 空链表和单节点链表自然适配。

# LC0056-合并区间

> 链接：[LeetCode 56](https://leetcode.cn/problems/merge-intervals/)

## 🧾 题目理解

给定若干区间，合并所有重叠区间，返回互不重叠且覆盖相同范围的区间集合。

## 💡 思路

先按左端点排序。遍历区间时，如果当前区间左端点不超过上一个合并区间的右端点，就更新右端点；否则开启一个新区间。

## ⏱️ 复杂度

- 时间复杂度：`O(n log n)`，瓶颈是排序。
- 空间复杂度：`O(n)`，用于保存答案。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
        List<int[]> ans = new ArrayList<>();
        for (int[] interval : intervals) {
            if (ans.isEmpty() || interval[0] > ans.get(ans.size() - 1)[1]) {
                ans.add(interval);
            } else {
                ans.get(ans.size() - 1)[1] = Math.max(ans.get(ans.size() - 1)[1], interval[1]);
            }
        }
        return ans.toArray(new int[ans.size()][]);
    }
}
```

## ⚠️ 易错点

- 必须按左端点排序，不是按右端点。
- 判断是否重叠用 `interval[0] <= last[1]`。
- 合并时右端点取最大值，不能直接覆盖。

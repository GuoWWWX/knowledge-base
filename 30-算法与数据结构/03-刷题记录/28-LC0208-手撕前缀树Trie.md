# LC0208-手撕前缀树 Trie (字典树)

> 链接：[LeetCode 208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/)  
> **大厂考情**：搜索框输入联想、敏感词过滤、路由前缀匹配高频必撕数据结构。

## 🧾 题目理解

**Trie**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 `Trie` 类：
- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word`。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即在检索到末尾的同时该节点被标记为单词结尾）；否则返回 `false`。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix` ，返回 `true` ；否则返回 `false`。

### 输入输出示例
```text
输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]

输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True
```

## 💡 思路分析：多叉树结构设计

Trie 的本质是一棵**多叉树**：
1. **节点结构 `TrieNode`**：
   - 树的边代表字符：对于只包含小写英文字母的场景，使用大小为 26 的数组 `TrieNode[] children` 存储子节点指针；
   - 结束标志位：布尔变量 `boolean isEnd`，用来区分“该节点只是某个更长单词的公共前缀”还是“这里刚好是一个完整单词的结尾”。
2. **`insert(word)` 流程**：
   - 从根节点 `root` 开始，逐个字符遍历 `word`；
   - 若 `cur.children[c - 'a'] == null`，说明该字符路径尚不存在，创建新节点挂载；
   - 指针下移：`cur = cur.children[c - 'a']`；
   - 遍历结束后，将最后落脚的节点打标 `cur.isEnd = true`。
3. **`search(word)` vs `startsWith(prefix)` 关键区别**：
   - 两者前序遍历逻辑完全一致，逐个查找路径节点；
   - 若途中任意字符对应的子节点为 `null`，直接返回 `false`；
   - 遍历完成后：`startsWith` 只要路径存在即可返回 `true`；而 `search` 必须要求当前节点的 `cur.isEnd == true` 才能返回 `true`！

## 💻 Java 标准白板手撕源码

```java
class Trie {

    // 1. 自定义多叉树节点
    private static class TrieNode {
        TrieNode[] children;
        boolean isEnd;

        TrieNode() {
            // 26 个小写英文字母的子节点槽位
            this.children = new TrieNode[26];
            this.isEnd = false;
        }
    }

    private final TrieNode root;

    public Trie() {
        this.root = new TrieNode();
    }

    /**
     * 向前缀树插入一个单词
     */
    public void insert(String word) {
        TrieNode cur = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (cur.children[idx] == null) {
                cur.children[idx] = new TrieNode();
            }
            cur = cur.children[idx];
        }
        cur.isEnd = true; // 标记单词终点
    }

    /**
     * 精确查找单词是否存在
     */
    public boolean search(String word) {
        TrieNode node = findPrefix(word);
        return node != null && node.isEnd;
    }

    /**
     * 查找是否有以 prefix 为前缀的单词
     */
    public boolean startsWith(String prefix) {
        return findPrefix(prefix) != null;
    }

    /**
     * 辅助公共方法：顺着前缀一直往下找，返回最后的落脚节点
     */
    private TrieNode findPrefix(String prefix) {
        TrieNode cur = root;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (cur.children[idx] == null) {
                return null; // 路径中断
            }
            cur = cur.children[idx];
        }
        return cur;
    }
}
```

## ⏱️ 复杂度分析

- **时间复杂度**：
  - `insert`：$O(L)$（$L$ 为单词长度，仅需线性扫描单词一次）；
  - `search` / `startsWith`：$O(L)$，与树中存储的单词总数量 $N$ 完全无关！
- **空间复杂度**：最坏情况下每个字符都创建一个新节点，空间为 $O(26 \times \sum L)$。

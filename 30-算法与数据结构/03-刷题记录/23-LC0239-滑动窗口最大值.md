# LC0239-滑动窗口最大值

> 链接：[LeetCode 239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)

## 🧾 题目理解

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。返回滑动窗口中的最大值。

- **输入**：`nums = [1,3,-1,-3,5,3,6,7], k = 3`
- **输出**：`[3,3,5,5,6,7]`

---

## 💡 思路

使用**单调递减双端队列（`Deque`）**维护窗口内可能成为最大值的候选下标：

1. **入队淘汰**：新下标 $i$ 入队时，凡是队尾对应元素 `nums[deque.peekLast()] <= nums[i]` 的，未来永远没有可能成为窗口最大值，立即从队尾弹出；
2. **过期淘汰**：若队首下标已经滑出窗口范围（`deque.peekFirst() < i - k + 1`），从队首弹出；
3. **记录最值**：当遍历到第 $k - 1$ 个元素后，窗口形成，当前队首 `nums[deque.peekFirst()]` 即为该窗口全局最大值。

---

## ⏱️ 复杂度

- **时间复杂度**：$O(n)$，每个下标最多入队一次、出队一次，总体双端队列操作为常数级均摊。
- **空间复杂度**：$O(k)$，双端队列中存储的最多为滑动窗口大小 $k$ 个下标。

---

## 💻 Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k <= 0) return new int[0];

        int n = nums.length;
        int[] ans = new int[n - k + 1];
        int idx = 0;

        // 存下标的双端队列
        Deque<Integer> deque = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 1. 淘汰队尾所有较小值
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();
            }
            deque.offerLast(i);

            // 2. 淘汰队首过期元素
            if (deque.peekFirst() < i - k + 1) {
                deque.pollFirst();
            }

            // 3. 记录当前窗口最大值
            if (i >= k - 1) {
                ans[idx++] = nums[deque.peekFirst()];
            }
        }
        return ans;
    }
}
```

---

## ⚠️ 易错点

- 双端队列存**数组下标**远比存数值省心，可以直接根据下标判断是否过期出窗。
- 移出过期元素用 `if` 即可，因为每次窗口只向右滑动 1 格，最多只有 1 个下标过期。

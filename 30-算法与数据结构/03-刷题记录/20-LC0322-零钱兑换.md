# LC0322-零钱兑换

> 链接：[LeetCode 322](https://leetcode.cn/problems/coin-change/)

## 🧾 题目理解

给定硬币面额和总金额，求凑成该金额所需的最少硬币数；无法凑成则返回 `-1`。

## 💡 思路

定义 `dp[i]` 为凑成金额 `i` 的最少硬币数。初始 `dp[0] = 0`，其他位置设为不可达的大值。对每个金额枚举硬币，若 `i - coin` 可达，则尝试用 `dp[i - coin] + 1` 更新。

## ⏱️ 复杂度

- 时间复杂度：`O(amount * coins.length)`。
- 空间复杂度：`O(amount)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public int coinChange(int[] coins, int amount) {
        int impossible = amount + 1;
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, impossible);
        dp[0] = 0;

        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (i >= coin) {
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }
        return dp[amount] == impossible ? -1 : dp[amount];
    }
}
```

## ⚠️ 易错点

- 不可达初始值用 `amount + 1`，避免整型最大值加一溢出。
- 完全背包允许同一硬币使用多次。
- 返回前要把不可达的大值转成 `-1`。

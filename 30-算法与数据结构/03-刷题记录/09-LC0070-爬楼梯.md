# LC0070-爬楼梯

> 链接：[LeetCode 70](https://leetcode.cn/problems/climbing-stairs/)

## 🧾 题目理解

每次可以爬 1 或 2 阶，求爬到第 `n` 阶的不同方法数。

## 💡 思路

到达第 `i` 阶只有两种最后一步：从 `i - 1` 爬 1 阶，或从 `i - 2` 爬 2 阶，所以 `f(i) = f(i - 1) + f(i - 2)`。只需要保留前两个状态。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        int prev2 = 1, prev1 = 2;
        for (int i = 3; i <= n; i++) {
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

## ⚠️ 易错点

- 初始值是 `f(1)=1, f(2)=2`。
- 循环边界从 3 到 `n`。
- 本题不是求最少步数，而是方案数。

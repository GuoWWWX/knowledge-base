# LC0001-两数之和

> 链接：[LeetCode 1](https://leetcode.cn/problems/two-sum/)

## 🧾 题目理解

给定数组 `nums` 和目标值 `target`，返回两个不同下标，使对应元素之和等于 `target`。题目保证只有一个答案。

## 💡 思路

从左到右扫描数组，用哈希表记录“值 -> 下标”。扫描到 `nums[i]` 时，先查 `target - nums[i]` 是否已经出现；如果出现，当前数和历史数组成答案；否则再把当前数写入哈希表。

关键是先查再存，避免同一个元素被使用两次。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

## 💻 Java 代码

```java
import java.util.*;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (seen.containsKey(need)) {
                return new int[] {seen.get(need), i};
            }
            seen.put(nums[i], i);
        }
        return new int[0];
    }
}
```

## ⚠️ 易错点

- 先存再查会在 `target = 2 * nums[i]` 时误用同一位置。
- 哈希表存下标，不是存出现次数。
- 允许重复值，不能用集合替代映射。

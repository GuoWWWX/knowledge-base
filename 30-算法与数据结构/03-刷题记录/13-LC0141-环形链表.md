# LC0141-环形链表

> 链接：[LeetCode 141](https://leetcode.cn/problems/linked-list-cycle/)

## 🧾 题目理解

判断链表中是否存在环。

## 💡 思路

使用快慢指针：慢指针每次走一步，快指针每次走两步。如果有环，快指针最终会在环内追上慢指针；如果无环，快指针会先到达链表尾部。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

## ⚠️ 易错点

- 循环条件必须检查 `fast` 和 `fast.next`。
- 比较节点引用，不是比较节点值。
- 空链表和单节点无环链表都应返回 `false`。

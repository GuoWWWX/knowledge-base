# LC0121-买卖股票的最佳时机

> 链接：[LeetCode 121](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

## 🧾 题目理解

给定每天股价，只能买入一次并在未来某天卖出一次，求最大利润；无法盈利则返回 0。

## 💡 思路

从左到右遍历价格，维护当前为止最低买入价 `minPrice`。每天都尝试以当天卖出，更新 `price - minPrice` 的最大值，然后更新最低价。

## ⏱️ 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 💻 Java 代码

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int ans = 0;
        for (int price : prices) {
            ans = Math.max(ans, price - minPrice);
            minPrice = Math.min(minPrice, price);
        }
        return ans;
    }
}
```

## ⚠️ 易错点

- 只能先买后卖，不能用未来低价买过去高价。
- 最大利润初始化为 0，允许不交易。
- 这是一次交易版本，多次交易不是同一个状态定义。

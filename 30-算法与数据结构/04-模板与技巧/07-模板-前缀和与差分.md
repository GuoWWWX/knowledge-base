# 模板-前缀和与差分

> [!abstract] 一句话总结
> 前缀和解决静态区间查询，差分解决批量区间更新。

## 前缀和

```java
int[] prefix = new int[n + 1];
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
}
int sum = prefix[r + 1] - prefix[l];
```

## 前缀和 + 哈希

```java
Map<Integer, Integer> map = new HashMap<>();
map.put(0, 1);
int prefix = 0, ans = 0;
for (int x : nums) {
    prefix += x;
    ans += map.getOrDefault(prefix - k, 0);
    map.put(prefix, map.getOrDefault(prefix, 0) + 1);
}
```

## 差分

```java
int[] diff = new int[n + 1];
diff[l] += val;
diff[r + 1] -= val;
```

恢复数组：

```java
int cur = 0;
for (int i = 0; i < n; i++) {
    cur += diff[i];
    nums[i] += cur;
}
```

## 二维前缀和

适合矩阵子区域求和，`sum[i][j]` 表示左上角到 `(i - 1, j - 1)` 的区域和。

```java
int[][] sum = new int[m + 1][n + 1];
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        sum[i + 1][j + 1] = sum[i][j + 1] + sum[i + 1][j] - sum[i][j] + grid[i][j];
    }
}
int ans = sum[x2 + 1][y2 + 1] - sum[x1][y2 + 1] - sum[x2 + 1][y1] + sum[x1][y1];
```

## 使用判断

- 多次查询静态区间和：前缀和。
- 多次区间加，最后一次性查询结果：差分。
- 子数组和等于 K，且有负数：前缀和 + 哈希；不能用滑动窗口。
- 数值可能很大时，前缀和数组优先用 `long`。

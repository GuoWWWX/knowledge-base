# 09 · 技巧：二分边界极简口诀与左右移动判定

> [!tip] 核心诉求
> 做算法题时，二分查找最让人头疼的就是：**什么时候 `left = mid + 1`？什么时候 `right = mid - 1`？为什么有时候写 `right = mid` 会死循环？最后答案到底返回 `left` 还是 `right`？**
> 
> 本文彻底抛弃复杂的数学证明，只给你**好记、好用、做题 3 秒内定乾坤的极简法则与速查口诀**！

---

## 一、 为什么二分会死循环？（30 秒识破根源）

在 Java 中，整数除法是**向下取整**的：
```java
int mid = left + (right - left) / 2;
```
当搜索区间只剩下两个相邻元素时（例如 `left = 0, right = 1`）：
- 计算出的 `mid = 0 + (1 - 0) / 2 = 0`，**`mid` 永远等于 `left`**！
- 如果你的分支里写了 `left = mid;`，那么 `left` 根本没有变化，下一轮 `mid` 依然是 0，**直接陷入无限死循环**！

> [!important] 避坑第一定律
> **只要在向下取整的二分中写 `left = mid`，就极有可能死循环！**
> 想要绝对不死循环，最省心、最对称的方案就是**闭区间双向严格缩圈（`mid + 1` 与 `mid - 1`）**。

## 二、 黄金万能模板：闭区间模型 `[left, right]`（强烈推荐）

闭区间模型是刷题时**心智负担最低、容错率最高**的模型。

### 1. 20 秒速背口诀
> **两头闭合带等号（`while (left <= right)`）；**
> **中点防溢做减法（`left + (right - left) / 2`）；**
> **排除必移一步走（`left = mid + 1`, `right = mid - 1`）；**
> **出圈必定会错位（终态必为 `left = right + 1`）；**
> **求小求左返回 `left`，求大求右返回 `right`！**

---

### 2. 核心题型代码与判定对照

#### ① 查找首个 $\ge target$ 的位置（最核心的 `lower_bound`）
只要会写这一个，其他所有边界都能一键转换！

```java
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length - 1; // 1. 两头闭合
    while (left <= right) {               // 2. 带等号
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {
            // 当前元素已经 >= target，说明答案在 mid 或 mid 的左边
            right = mid - 1; // 答案可能就是 mid，缩小右边界继续往左看
        } else {
            // 当前元素 < target，说明答案必定在 mid 右侧
            left = mid + 1;
        }
    }
    // 退出时: right 在左边，left 在右边 (left = right + 1)
    // left 停在首个 >= target 的位置上！
    return left;
}
```

#### ② 查找最后一个 $\le target$ 的位置

```java
public int upperBoundOrEqual(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            // 答案在 mid 或 mid 的右侧，缩小左边界继续往右探
            left = mid + 1; 
        } else {
            right = mid - 1;
        }
    }
    // 退出时: right 停在最后一个 <= target 的位置上！
    return right;
}
```

## 三、 四大边界转换神器（只记一个 `lower_bound` 即可）

在面试和比赛中，千万不要去背 4 套不同的二分代码，容易记混。**全部用 `lower_bound` 一行转化**：

| 查询需求 | 转化公式 | 解释说明 |
| :--- | :--- | :--- |
| **首个 $\ge x$** | `lowerBound(nums, x)` | 标准原型（红蓝分界点） |
| **首个 $> x$** | `lowerBound(nums, x + 1)` | 严格大于 $x$，等价于大于等于 $x + 1$（整数域） |
| **最后一个 $< x$** | `lowerBound(nums, x) - 1` | 首个 $\ge x$ 的前一个元素 |
| **最后一个 $\le x$** | `lowerBound(nums, x + 1) - 1` | 首个 $> x$ 的前一个元素 |

> [!example] 实战：LC 34 在排序数组中查找元素的第一个和最后一个位置
> ```java
> public int[] searchRange(int[] nums, int target) {
>     int start = lowerBound(nums, target);
>     // 越界检查或值不匹配
>     if (start == nums.length || nums[start] != target) {
>         return new int[]{-1, -1};
>     }
>     // 最后一个等于 target 的位置，等价于 (首个 > target) - 1
>     int end = lowerBound(nums, target + 1) - 1;
>     return new int[]{start, end};
> }
> ```

## 四、 左闭右开模型 `[left, right)` 什么时候用？

很多同学看题解经常看到 `while (left < right)`，那它到底怎么判断加减 1？

- **区间定义**：`left = 0, right = nums.length`（右端是开的，取不到）；
- **循环条件**：`while (left < right)`（相遇即退出）；
- **指针移动法则**：
  - 如果 `mid` 不符合条件，`mid` 必须排除：`left = mid + 1`；
  - 如果 `mid` 可能是解，因为右端开，要把 `mid` 包含在右边界外侧：**`right = mid;`（不用减 1）**。
- **退出结果**：`left == right`，返回 `left` 或 `right` 都一样。

```java
// 左闭右开写法示例
int left = 0, right = nums.length;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] >= target) {
        right = mid;     // 保留 mid 作为右开区间边界
    } else {
        left = mid + 1;  // mid 肯定不是解，排除
    }
}
return left; // left == right
```

## 五、 二分答案法（二分值域）30 秒解题模板

当题目出现以下字眼时，90% 是二分答案：
- **“求满足条件的最大值中最小值”** / **“求满足条件的最小值中最大值”**；
- 能够轻易写出一个 `check(mid)` 函数：如果 `mid` 可以满足，那么更小（或更大）的值一定也可以（具有二段性）。

### 极简骨架
```java
public int binarySearchAns(int[] nums, int condition) {
    int left = 1;                 // 答案可能的最小值
    int right = 1_000_000_000;    // 答案可能的最大值
    int ans = -1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(nums, mid, condition)) {
            ans = mid;           // 记录当前可行解

        }
    }
    return ans;
```

## 六、 记忆卡片速查表（截图保存）

| 维度 | 闭区间 `[left, right]` (推荐) | 左闭右开 `[left, right)` |
| :--- | :--- | :--- |
| **右边界初值** | `nums.length - 1` | `nums.length` |
| **循环条件** | `left <= right` | `left < right` |
| **左移动** | `left = mid + 1` | `left = mid + 1` |
| **右移动** | `right = mid - 1` | `right = mid` |
| **死循环风险** | 零风险 | `left = mid` 会死循环 |
| **首个 $\ge$ 返回值** | 返回 `left` | 返回 `left` |
| **最后一个 $\le$ 返回值** | 返回 `right` | 返回 `left - 1` |

# 模板-滑动窗口

> [!abstract] 一句话总结
> 滑动窗口模板通过右指针扩张、左指针收缩，在 O(n) 内处理连续区间问题。

## 可变窗口模板

```java
int left = 0, ans = 0;
for (int right = 0; right < nums.length; right++) {
    add(nums[right]);
    while (windowInvalid()) {
        remove(nums[left]);
        left++;
    }
    ans = Math.max(ans, right - left + 1);
}
```

## 最小覆盖模板

```java
int left = 0, best = Integer.MAX_VALUE;
for (int right = 0; right < s.length(); right++) {
    add(s.charAt(right));
    while (windowValid()) {
        best = Math.min(best, right - left + 1);
        remove(s.charAt(left++));
    }
}
```

## 检查点

- 窗口内维护什么：计数、和、不同字符数、最大值。
- 什么时候收缩：窗口非法时，或窗口已经满足条件时。
- 什么时候更新答案：收缩前还是收缩后。

## 固定长度模板

```java
int sum = 0, ans = Integer.MIN_VALUE;
for (int right = 0; right < nums.length; right++) {
    sum += nums[right];
    if (right >= k) {
        sum -= nums[right - k];
    }
    if (right >= k - 1) {
        ans = Math.max(ans, sum);
    }
}
```

## 选择模板

| 问法 | 收缩条件 | 答案更新 |
| ---- | -------- | -------- |
| 最长合法窗口 | 窗口非法时收缩 | 收缩后更新最大长度 |
| 最短满足窗口 | 窗口满足时收缩 | 收缩前更新最小长度 |
| 固定长度窗口 | 长度超过 k 时移除 | 长度等于 k 时更新 |

## 易错点

- 有负数的“和为 K 子数组”通常不能用滑动窗口，要用前缀和。
- 字符串窗口里 `valid` 表示满足条件的字符种类数，不一定等于窗口长度。
- `left` 每移动一步，都要同步撤销窗口状态。

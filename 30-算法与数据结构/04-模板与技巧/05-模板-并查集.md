# 模板-并查集

> [!abstract] 一句话总结
> 并查集模板用 parent 表示父节点，用路径压缩和按大小合并优化连通性查询。

## 📌 适用场景

- 判断两个元素是否属于同一个集合。
- 统计连通分量数量。
- 动态合并关系，例如朋友圈、省份数量、冗余连接。
- Kruskal 最小生成树中按边权从小到大合并端点。

## 🧩 核心操作

| 操作 | 含义 | 复杂度 |
| ---- | ---- | ------ |
| `find(x)` | 查询 x 所在集合代表元 | 近似 O(1) |
| `union(a,b)` | 合并两个集合 | 近似 O(1) |
| `count` | 当前连通分量数量 | O(1) |

## 💻 Java 模板

```java
class DSU {
    int[] parent;
    int[] size;
    int count;

    DSU(int n) {
        parent = new int[n];
        size = new int[n];
        count = n;
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (size[ra] < size[rb]) {
            int t = ra; ra = rb; rb = t;
        }
        parent[rb] = ra;
        size[ra] += size[rb];
        count--;
        return true;
    }
}
```

## ⚠️ 易错点

- `find` 必须做路径压缩，否则树高可能退化。
- `union` 前要先找根节点，不要直接改原节点父指针。
- 节点编号如果从 1 开始，要么数组开 `n + 1`，要么统一映射到 0 开始。
- 如果题目需要集合大小、权值关系、连通分量数，要在 `union` 时同步维护。

## 🎯 面试问题

> [!question] 高频问题
> - Q: 并查集为什么快？
>   - A: 路径压缩会把查找路径上的节点直接挂到根节点，按大小/秩合并避免树过高，两者结合后均摊复杂度近似 O(1)。
> - Q: 并查集不能解决什么？
>   - A: 它擅长合并和查询连通性，但不擅长删除边；如果要动态删边，需要离线倒序、线段树分治或其他动态图结构。

# 模板-单调栈

> [!abstract] 一句话总结
> 单调栈用于在 O(n) 内寻找每个元素左/右侧第一个更大或更小的元素。

## 下一个更大元素

```java
int[] ans = new int[nums.length];
Arrays.fill(ans, -1);
Deque<Integer> st = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    while (!st.isEmpty() && nums[st.peek()] < nums[i]) {
        ans[st.pop()] = nums[i];
    }
    st.push(i);
}
```

## 精通重点

- 栈里存下标，比存值更灵活。
- 递增栈找下一个更小，递减栈找下一个更大。
- 循环数组可遍历 `2 * n` 次并取模。

## 典型题型

| 题型 | 维护什么栈 | 说明 |
| ---- | ---------- | ---- |
| 下一个更大元素 | 单调递减栈 | 新元素更大时弹出旧元素 |
| 每日温度 | 单调递减栈 | 答案是下标距离 |
| 柱状图最大矩形 | 单调递增栈 | 弹出时计算以当前高度为最低的宽度 |
| 接雨水 | 单调递减栈 | 弹出低洼位置计算蓄水 |

## 易错点

- 栈里通常存下标，因为要计算距离或宽度。
- 判断条件中的 `<` / `<=` 会影响重复元素处理。
- 循环数组要防止第二轮重复入栈，通常只在 `i < n` 时 push。

## 面试问题

> [!question] 高频问题
> - Q: 单调栈为什么是 O(n)？
>   - A: 每个元素最多入栈一次、出栈一次，所以总操作次数是线性的。
> - Q: 什么时候想到单调栈？
>   - A: 题目要求找每个元素左右第一个更大/更小元素，或需要维护一个局部单调结构时。

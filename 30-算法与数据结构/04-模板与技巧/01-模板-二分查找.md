# 模板-二分查找

> [!abstract] 一句话总结
> 二分查找的本质是在“有单调性”的搜索空间里，每一步排除一半不可能答案。

## 📌 适用场景

- 有序数组中查找某个值、左边界、右边界。
- 在答案空间上二分，例如最小可行速度、最大可行容量。
- 旋转数组、峰值、矩阵搜索等变形题，本质仍然要找到可排除的一半。

## 🧩 核心不变量

| 写法 | 区间含义 | 循环条件 | 常见用途 |
| ---- | -------- | -------- | -------- |
| 左闭右开 | `[l, r)` | `l < r` | lower_bound / upper_bound |
| 左闭右闭 | `[l, r]` | `l <= r` | 查找确定值 |

> [!important] 只选一种区间语义
> 面试时最容易错的不是 mid，而是循环条件、边界更新和返回值混用了两种区间定义。

## ⚙️ lower_bound 模板

查找第一个 `>= target` 的位置。

```java
int lowerBound(int[] nums, int target) {
    int l = 0, r = nums.length; // [l, r)
    while (l < r) {
        int m = l + (r - l) / 2;
        if (nums[m] >= target) {
            r = m;
        } else {
            l = m + 1;
        }
    }
    return l;
}
```

## ⚙️ upper_bound 模板

查找第一个 `> target` 的位置。

```java
int upperBound(int[] nums, int target) {
    int l = 0, r = nums.length;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (nums[m] > target) {
            r = m;
        } else {
            l = m + 1;
        }
    }
    return l;
}
```

## 🧠 答案二分

答案二分不是在数组里找数，而是在答案范围里找“第一个满足条件的答案”。

```java
int minAnswer(int left, int right) {
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```

`check(mid)` 必须具备单调性：如果 `mid` 可行，那么更大的值都可行；或反过来。

## ⚠️ 易错点

- `mid = (l + r) / 2` 可能溢出，推荐 `l + (r - l) / 2`。
- 返回位置后要检查是否越界，以及 `nums[pos]` 是否真等于目标。
- 答案二分先证明单调性，再写代码。
- 左闭右开写法中，`r` 初始是 `nums.length`，不是最后一个下标。

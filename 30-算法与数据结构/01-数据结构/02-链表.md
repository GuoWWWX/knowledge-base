# 链表

> [!abstract] 一句话总结
> 链表通过指针连接节点，擅长 O(1) 插入删除，但随机访问是 O(n)。

## 核心技巧

| 技巧 | 解决什么 | 典型题 |
| ---- | -------- | ------ |
| 虚拟头节点 | 统一删除头节点和中间节点 | 删除链表元素、合并链表 |
| 快慢指针 | 找中点、判环、倒数第 K 个 | 环形链表 |
| 三指针反转 | 原地反转 next 指向 | 反转链表 |
| 递归 | 处理子链表后回接 | 两两交换节点 |

## 反转模板

```java
ListNode prev = null, cur = head;
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
return prev;
```

## 虚拟头节点模板

```java
ListNode dummy = new ListNode(0);
dummy.next = head;
ListNode prev = dummy;
while (prev.next != null) {
    if (shouldDelete(prev.next)) {
        prev.next = prev.next.next;
    } else {
        prev = prev.next;
    }
}
return dummy.next;
```

## 合并两个有序链表

```java
ListNode dummy = new ListNode(0), tail = dummy;
while (l1 != null && l2 != null) {
    if (l1.val <= l2.val) {
        tail.next = l1;
        l1 = l1.next;
    } else {
        tail.next = l2;
        l2 = l2.next;
    }
    tail = tail.next;
}
tail.next = l1 != null ? l1 : l2;
return dummy.next;
```

## 易错点

- 修改 `cur.next` 前必须先保存 `next`。
- 删除节点时要操作前驱节点。
- 快慢指针循环条件通常是 `fast != null && fast.next != null`。
- 链表题先画指针变化，尤其是反转、分割、两两交换。

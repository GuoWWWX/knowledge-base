# 二叉树与遍历

> [!abstract] 一句话总结
> 二叉树题的核心是递归定义：当前节点能从左右子树拿到什么，又要向父节点返回什么。

## 遍历方式

| 遍历 | 顺序 | 用途 |
| ---- | ---- | ---- |
| 前序 | 根左右 | 复制树、序列化、路径构造 |
| 中序 | 左根右 | BST 有序输出 |
| 后序 | 左右根 | 树形 DP、删除、子树信息汇总 |
| 层序 | BFS | 最短层数、按层输出 |

## 递归模板

```java
void dfs(TreeNode root) {
    if (root == null) return;
    // 前序位置
    dfs(root.left);
    // 中序位置
    dfs(root.right);
    // 后序位置
}
```

## 精通重点

- 能判断题目要用前序、中序、后序还是层序。
- 能把“返回值”设计清楚，例如高度、是否平衡、最大路径和。
- 能写递归版，也能用栈写迭代版。

## 两种递归视角

### 自顶向下

父节点把路径、深度、当前状态传给子节点，适合路径和、最大深度、从根到叶子的枚举。

### 自底向上

子节点把高度、是否平衡、最大贡献值返回给父节点，适合平衡二叉树、直径、最近公共祖先、最大路径和。

## 层序模板

```java
Queue<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    int size = q.size();
    for (int i = 0; i < size; i++) {
        TreeNode node = q.poll();
        if (node.left != null) q.offer(node.left);
        if (node.right != null) q.offer(node.right);
    }
}
```

## 易错点

- 递归函数先定义“返回什么”，再写左右子树调用。
- 空节点的返回值要和题意匹配：高度常返回 0，求最大值时可能返回极小值。
- 层序遍历如果要分层输出，必须在循环开始记录当前队列大小。

# 二叉搜索树

> [!abstract] 一句话总结
> BST 的中序遍历有序，所有操作都围绕“左小右大”的不变量展开。

## 核心性质

- 左子树所有节点值小于当前节点。
- 右子树所有节点值大于当前节点。
- 中序遍历得到升序序列。

## 常见题型

- 验证 BST：递归传上下界。
- 查找/插入：按大小走左或右。
- 第 K 小：中序遍历计数。
- 最近公共祖先：利用大小关系剪枝。

## 验证模板

```java
boolean valid(TreeNode root, long low, long high) {
    if (root == null) return true;
    if (root.val <= low || root.val >= high) return false;
    return valid(root.left, low, root.val)
        && valid(root.right, root.val, high);
}
```

## 中序迭代模板

```java
Deque<TreeNode> stack = new ArrayDeque<>();
TreeNode cur = root;
while (cur != null || !stack.isEmpty()) {
    while (cur != null) {
        stack.push(cur);
        cur = cur.left;
    }
    cur = stack.pop();
    // 访问 cur，BST 中序应当递增
    cur = cur.right;
}
```

## 删除节点思路

- 没有子节点：直接删除。
- 只有一个子节点：用子节点替换当前节点。
- 有两个子节点：用右子树最小节点或左子树最大节点替换，再删除那个替换节点。

## 复杂度

普通 BST 平均操作 O(log n)，但在有序插入时会退化为 O(n)。需要稳定性能时使用平衡树。

## 易错点

- 不能只比较当前节点和左右孩子，要约束整棵子树上下界。
- 注意重复值规则，面试时先问清楚。

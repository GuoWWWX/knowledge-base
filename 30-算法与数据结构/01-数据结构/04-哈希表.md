# 哈希表

> [!abstract] 一句话总结
> 哈希表用额外空间换平均 O(1) 查找，是计数、去重、映射和前缀和问题的基础工具。

## 常见用途

- 查补数：两数之和。
- 计数：字符频次、出现次数。
- 去重：集合判重。
- 前缀和映射：统计和为 K 的子数组。

## Java 模板

```java
Map<Integer, Integer> freq = new HashMap<>();
for (int x : nums) {
    freq.put(x, freq.getOrDefault(x, 0) + 1);
}
```

## 典型模式

### 查找补数

边遍历边记录已出现元素，避免同一个元素被重复使用。

```java
Map<Integer, Integer> index = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];
    if (index.containsKey(need)) return new int[]{index.get(need), i};
    index.put(nums[i], i);
}
```

### 频次统计

适合“出现次数”“多数元素”“异位词分组”等问题。固定小字符集时可以用数组替代 `HashMap`，更快也更简单。

### 前缀状态映射

当题目问“有多少个区间满足某条件”时，哈希表常用来记录历史前缀状态出现次数。

## 复杂度

- 平均插入、查询、删除是 O(1)。
- 最坏情况下会退化；Java `HashMap` 在桶内元素过多时会树化，降低极端冲突风险。
- 空间复杂度通常是 O(n)，用空间换时间。

## 易错点

- 自定义对象作 key 要实现 `equals/hashCode`。
- 哈希表平均 O(1)，最坏仍可能退化。
- 统计前缀和时初始要放 `map.put(0, 1)`。
- 遍历中删除 `Map` 元素要用迭代器或先收集 key，避免并发修改异常。

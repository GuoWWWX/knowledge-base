# 堆与优先队列

> [!abstract] 一句话总结
> 堆用于快速获取当前最小或最大元素，Java 中常用 `PriorityQueue` 实现。

## 常见场景

- Top K 问题。
- 合并 K 个有序链表。
- 数据流中位数。
- Dijkstra 最短路。

## Java 模板

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
```

Top K 小根堆：

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
for (int x : nums) {
    pq.offer(x);
    if (pq.size() > k) pq.poll();
}
return pq.peek();
```

## TopK 口诀

- 求第 K 大：维护大小为 K 的小根堆，堆顶就是当前第 K 大。
- 求第 K 小：维护大小为 K 的大根堆，堆顶就是当前第 K 小。
- 求前 K 个高频：先统计频次，再用堆按频次排序。

## Dijkstra 中的用法

堆里保存“当前距离最小的候选点”。Java 没有 decrease-key，常见做法是允许旧状态留在堆里，弹出时判断是否过期。

```java
if (curDist > dist[u]) continue;
```

## 复杂度

- 插入和弹出堆顶：O(log n)。
- 查看堆顶：O(1)。
- TopK 扫描 `n` 个元素、堆大小为 `k`：O(n log k)。

## 易错点

- `PriorityQueue` 默认小根堆。
- 比较器 `b - a` 可能溢出，安全写法是 `Integer.compare(b, a)`。
- 堆只能快速拿堆顶，不能 O(1) 查任意元素。
- 堆不保证整体有序，只保证每次 `poll()` 拿到当前优先级最高的元素。

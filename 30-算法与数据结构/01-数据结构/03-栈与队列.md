# 栈与队列

> [!abstract] 一句话总结
> 栈适合处理“最近未匹配”的问题，队列适合按层或按时间顺序推进状态。

## 核心对比

| 结构 | 特点 | 高频场景 |
| ---- | ---- | -------- |
| 栈 | 后进先出 | 括号匹配、单调栈、递归模拟 |
| 队列 | 先进先出 | BFS、层序遍历、滑动窗口 |
| 双端队列 | 两端进出 | 单调队列、窗口最值 |

## Java 写法

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);
int top = stack.pop();

Queue<Integer> queue = new ArrayDeque<>();
queue.offer(1);
int first = queue.poll();
```

## 单调栈

维护一个单调递增或递减的栈，用来寻找每个元素左/右侧第一个更大或更小的元素。

```java
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
        int idx = stack.pop();
        // nums[i] 是 idx 右侧第一个更大元素
    }
    stack.push(i);
}
```

## 单调队列

维护窗口内候选最大值或最小值，常用于滑动窗口最值。

```java
Deque<Integer> deque = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    while (!deque.isEmpty() && deque.peekFirst() <= i - k) deque.pollFirst();
    while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) deque.pollLast();
    deque.offerLast(i);
}
```

## 易错点

- Java 不推荐用旧的 `Stack` 类，优先 `ArrayDeque`。
- `poll()` 空队列返回 null，`remove()` 会抛异常。
- BFS 按层遍历时要先记录当前层 size。
- `ArrayDeque` 不能存 `null`。

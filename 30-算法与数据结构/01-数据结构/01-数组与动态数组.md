# 数组与动态数组

> [!abstract] 一句话总结
> 数组用连续内存支持 O(1) 随机访问，动态数组在容量不足时扩容复制，用空间换取均摊追加效率。

## 核心概念

| 概念 | 含义 | 重点 |
| ---- | ---- | ---- |
| 下标访问 | 通过 `base + index * size` 定位 | O(1) |
| 扩容 | 容量不足时申请更大数组并复制 | 单次 O(n)，均摊 O(1) |
| 原地覆盖 | 双指针覆盖无效元素 | 删除类题高频 |
| 前缀和 | 用累积值快速求区间和 | 子数组问题基础 |

## 常见题型

- 原地删除/移动零：快慢指针。
- 两数之和/去重：哈希或排序双指针。
- 区间和：前缀和。
- 差分数组：批量区间更新。

## Java 模板

```java
int slow = 0;
for (int fast = 0; fast < nums.length; fast++) {
    if (isValid(nums[fast])) {
        nums[slow++] = nums[fast];
    }
}
```

## 易错点

- 删除元素后数组长度和有效长度不是一回事。
- 扩容复制会造成瞬时 O(n) 开销。
- 前缀和下标建议用 `prefix[i + 1]` 表示前 i 个元素和。

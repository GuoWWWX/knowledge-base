# 图的表示

> [!abstract] 一句话总结
> 图由点和边组成，表示方式决定遍历、最短路、连通性和空间复杂度。

## 表示方式

| 方式 | 空间 | 适合 |
| ---- | ---- | ---- |
| 邻接矩阵 | O(n²) | 点少、查边快 |
| 邻接表 | O(n + m) | 稀疏图、高频遍历 |
| 边集 | O(m) | Kruskal、批量排序边 |

## 邻接表模板

```java
List<Integer>[] graph = new ArrayList[n];
for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
for (int[] e : edges) {
    graph[e[0]].add(e[1]);
    graph[e[1]].add(e[0]); // 无向图
}
```

带权图常用 `Edge` 保存终点和权重。

```java
class Edge {
    int to;
    int weight;
    Edge(int to, int weight) {
        this.to = to;
        this.weight = weight;
    }
}
List<Edge>[] graph = new ArrayList[n];
```

## 题目建图步骤

1. 明确节点是什么：编号、单词、网格坐标或状态。
2. 明确边是什么：直接给定、相邻移动、可转换关系或依赖关系。
3. 明确方向：有向、无向、带权、无权。
4. 明确算法：连通性用 DFS/BFS/并查集，最短路用 BFS/Dijkstra，最小生成树用 Kruskal/Prim。

## 复杂度选择

- 点数小且查边频繁：邻接矩阵。
- 边数远小于 `n²`：邻接表。
- 需要按权重排序边：边集。

## 易错点

- 有向图和无向图建边不同。
- 节点编号可能从 1 开始，要统一映射。
- 图搜索要记录 visited，防止环导致死循环。
- 网格图不一定要显式建图，很多时候用方向数组直接搜索更省空间。

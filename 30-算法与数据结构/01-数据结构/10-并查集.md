# 并查集

> [!abstract] 一句话总结
> 并查集用于维护动态连通性，支持快速合并集合和查询两个元素是否同属一个集合。

## 核心操作

- `find(x)`：找到 x 所在集合代表元。
- `union(a, b)`：合并 a 和 b 所在集合。
- 路径压缩 + 按大小合并后，复杂度近似 O(1)。

## Java 模板

```java
class DSU {
    int[] parent, size;
    DSU(int n) {
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    void union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return;
        if (size[ra] < size[rb]) {
            int t = ra; ra = rb; rb = t;
        }
        parent[rb] = ra;
        size[ra] += size[rb];
    }
}
```

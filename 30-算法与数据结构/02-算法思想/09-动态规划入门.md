# 动态规划入门

> [!abstract] 一句话总结
> 动态规划通过保存子问题答案避免重复计算，关键是状态定义和转移方程。

## 四步法

1. 定义 `dp[i]` 或 `dp[i][j]` 的含义。
2. 写出状态转移。
3. 初始化边界。
4. 确定遍历顺序。

## 示例：爬楼梯

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

## 精通重点

- 能从暴力递归推到记忆化搜索，再推到 DP 表。
- 能解释遍历顺序为什么不能反。
- 能做空间压缩但不牺牲可读性。

## 常见状态设计

| 场景 | 状态示例 | 解释 |
| ---- | -------- | ---- |
| 一维序列 | `dp[i]` | 以第 `i` 个元素结尾，或前 `i` 个元素的答案 |
| 双序列 | `dp[i][j]` | `s1[0..i)` 与 `s2[0..j)` 的答案 |
| 区间 | `dp[l][r]` | 区间 `[l,r]` 的答案 |
| 背包 | `dp[c]` | 容量为 `c` 时的最优值/可行性/方案数 |

## 从递归到 DP

1. 先写出暴力递归，确认每个函数参数代表一个状态。
2. 发现重复子问题后加缓存，得到记忆化搜索。
3. 根据依赖关系改成表格递推。
4. 如果当前状态只依赖少量历史状态，再考虑空间压缩。

## 易错点

- `dp[i]` 是“以 i 结尾”还是“前 i 个”必须先定清楚。
- 初始化不是随便填 0，最小值问题常需要 `INF`。
- 计数问题注意是否取模，最值问题注意不可达状态。

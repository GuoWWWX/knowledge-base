# 双指针

> [!abstract] 一句话总结
> 双指针用两个位置变量协同推进，常用于有序数组、链表、原地覆盖和区间收缩。

## 常见模型

| 模型 | 指针含义 | 例子 |
| ---- | -------- | ---- |
| 对撞指针 | 左右两端向中间收缩 | 两数之和、三数之和 |
| 快慢指针 | 一个快一个慢 | 环形链表、删除重复项 |
| 同向指针 | 维护窗口或有效区 | 移动零、原地删除 |

## 模板

```java
int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return true;
    if (sum < target) left++;
    else right--;
}
```

## 快慢指针模板

```java
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
```

常用于找中点、判断环、寻找环入口。判断环入口时，快慢指针相遇后，让一个指针回到头节点，两者每次走一步，再次相遇处就是入口。

## 去重扫描模板

```java
int write = 0;
for (int read = 0; read < nums.length; read++) {
    if (write == 0 || nums[read] != nums[write - 1]) {
        nums[write++] = nums[read];
    }
}
```

适合有序数组原地去重、移动元素、保留满足条件的元素。

## 易错点

- 对撞指针通常要求有序或可排序。
- 去重时要跳过同值，否则三数之和会重复。
- 链表快慢指针要注意 `fast.next` 判空。
- 双指针能成立的关键是每次移动都能排除一批不可能答案。

# 排序算法

> [!abstract] 一句话总结
> 排序是很多算法的预处理步骤，核心是理解稳定性、复杂度、原地性和排序后能获得的单调性。

## 对比表

| 算法 | 平均时间 | 稳定 | 适合 |
| ---- | -------- | ---- | ---- |
| 快排 | O(n log n) | 否 | 通用内存排序 |
| 归并 | O(n log n) | 是 | 链表排序、逆序对 |
| 堆排 | O(n log n) | 否 | TopK、优先队列 |
| 计数排序 | O(n + k) | 可稳定 | 值域小 |

## Java 注意

- `Arrays.sort(int[])` 对基本类型使用优化快排/双轴快排思路。
- `Arrays.sort(Object[])` 稳定，适合对象排序。
- Comparator 要避免 `a - b` 溢出。

## 排序带来的能力

- 单调性：排序后可以二分、双指针、贪心扫描。
- 相邻性：最接近、重复元素、区间重叠常在相邻元素之间判断。
- 分组性：相同 key 聚在一起，便于统计频次或合并。

## 常用 Comparator

```java
Arrays.sort(intervals, (a, b) -> {
    if (a[0] != b[0]) return Integer.compare(a[0], b[0]);
    return Integer.compare(a[1], b[1]);
});
```

对象排序时优先使用 `Integer.compare`、`Long.compare`，避免 `a - b` 在极值场景溢出。

## 面试高频问法

- 快排为什么平均 O(n log n)、最坏 O(n^2)：划分越平衡越接近 O(n log n)，极端不平衡会退化。
- 归并为什么稳定：相等元素合并时先取左侧元素，原相对顺序不变。
- 堆排为什么不稳定：堆调整会跨距离交换元素。

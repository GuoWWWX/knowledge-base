# 二分查找

> [!abstract] 一句话总结
> 二分查找不是“数组有序就套模板”，而是在单调条件下持续缩小答案空间。

## 精通重点

- 明确搜索空间：数组下标、答案范围、时间、容量。
- 明确 `check(mid)` 的单调性。
- 统一区间定义，推荐左闭右开写 lower_bound。

## 判断信号

| 信号 | 说明 |
| ---- | ---- |
| 有序数组 | 直接按下标二分 |
| 单调答案 | 用 `check(mid)` 判断可行性 |
| 最小化最大值 | 常见答案二分，如分割数组、运货能力 |
| 旋转有序 | 每次判断哪一半仍有序 |

## 高频变形

- 查找插入位置。
- 搜索旋转排序数组。
- 寻找峰值。
- 最小化最大值、最大化最小值。

## 易错点

- 没有先定义搜索区间，导致 `l <= r` 和 `l < r` 混用。
- `mid = (l + r) / 2` 在大整数范围可能溢出。
- 返回下标后忘记检查是否越界或是否真的等于目标。
- 答案二分没有证明 `check` 单调性。

## 面试问题

> [!question] 高频问题
> - Q: 二分查找一定要求数组有序吗？
>   - A: 不一定。数组有序只是最常见场景，本质要求是搜索空间存在可排除一半的单调性。
> - Q: lower_bound 和普通查找有什么区别？
>   - A: lower_bound 找第一个满足 `>= target` 的位置，即使 target 不存在也返回插入点。

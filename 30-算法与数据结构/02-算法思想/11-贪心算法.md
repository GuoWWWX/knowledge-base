# 贪心算法

> [!abstract] 一句话总结
> 贪心每一步选择当前最优，希望推出全局最优；难点在证明而不是代码。

## 判断信号

- 局部选择不会影响未来更优解。
- 可以用交换论证或反证法证明。
- 常见于区间、排序、调度、买卖股票。

## 证明套路

### 交换论证

假设存在一个最优解没有采用当前贪心选择，尝试把它的第一步替换成贪心选择，并证明替换后答案不变差。区间调度中“优先选择结束时间最早的区间”就是典型例子。

### 反证法

假设贪心选择无法得到最优解，再推出它与题目约束或最优解定义矛盾。适合“每一步必须尽量省/尽量早/尽量小”的问题。

## 常见模型

| 模型 | 贪心策略 | 代表题 |
| ---- | -------- | ------ |
| 区间选择 | 按结束时间排序 | 无重叠区间 |
| 区间合并 | 按起点排序，维护当前右边界 | 合并区间 |
| 股票一次交易 | 维护历史最低价 | 买卖股票 I |
| 跳跃覆盖 | 维护当前可达最远位置 | 跳跃游戏 |

## 示例思路

买卖股票 I：维护历史最低价，每天尝试卖出更新最大利润。

```java
int min = Integer.MAX_VALUE, ans = 0;
for (int price : prices) {
    min = Math.min(min, price);
    ans = Math.max(ans, price - min);
}
```

## 易错点

- 贪心策略想出来后必须证明。
- 有些题看似贪心，实际需要 DP。
- 排序只是手段，不是证明；面试时要解释为什么按这个字段排序。

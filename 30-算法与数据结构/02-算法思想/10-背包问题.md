# 背包问题

> [!abstract] 一句话总结
> 背包问题是 DP 经典模型，核心区别是每个物品能选一次、无限次还是有限次。

## 0-1 背包

```java
for (int i = 0; i < n; i++) {
    for (int c = capacity; c >= weight[i]; c--) {
        dp[c] = Math.max(dp[c], dp[c - weight[i]] + value[i]);
    }
}
```

容量倒序，防止同一物品被重复使用。

## 完全背包

```java
for (int i = 0; i < n; i++) {
    for (int c = weight[i]; c <= capacity; c++) {
        dp[c] = Math.max(dp[c], dp[c - weight[i]] + value[i]);
    }
}
```

容量正序，允许同一物品重复使用。

## 常见变形

- 最值：最大价值、最少硬币数。
- 可行性：能否装满。
- 计数：有多少种方案。

## 初始化原则

- 求最大价值且允许不装满：`dp` 可以初始化为 0。
- 要求恰好装满：除 `dp[0]=0` 外，其余位置初始化为不可达，如 `-INF`。
- 求最少数量：除 `dp[0]=0` 外，其余位置初始化为 `INF`。
- 求方案数：`dp[0]=1` 表示“什么都不选也是一种方案”。

## 遍历顺序口诀

| 类型 | 物品循环 | 容量循环 | 原因 |
| ---- | -------- | -------- | ---- |
| 0-1 背包 | 外层物品 | 倒序 | 防止同一物品重复使用 |
| 完全背包 | 外层物品 | 正序 | 允许同一物品多次使用 |
| 组合数 | 外层物品 | 内层容量 | 不关心顺序 |
| 排列数 | 外层容量 | 内层物品 | 关心顺序 |

## 面试表达

背包题最容易被问“为什么倒序”。回答时要抓住本质：一维压缩后，`dp[c - w]` 如果来自当前轮更新，就等于同一物品被选了多次；倒序能保证它仍然来自上一轮物品集合。

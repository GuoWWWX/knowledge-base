# 位运算

> [!abstract] 一句话总结
> 位运算把整数看成二进制状态，适合集合压缩、奇偶判断、异或消除和低位操作。

## 常用技巧

| 表达式 | 含义 |
| ------ | ---- |
| `x & 1` | 判断奇偶 |
| `x & (x - 1)` | 去掉最低位的 1 |
| `x & -x` | 取最低位的 1 |
| `a ^ a = 0` | 异或抵消 |
| `mask | (1 << i)` | 加入第 i 个状态 |

## 应用

- 只出现一次的数字。
- 子集枚举。
- 状态压缩 DP。
- 权限/开关状态表示。

## 必背模式

### 异或消除

`a ^ a = 0`、`a ^ 0 = a`，所以一组数中只有一个数出现奇数次时，可以用异或把成对元素全部抵消。

```java
int ans = 0;
for (int x : nums) {
    ans ^= x;
}
return ans;
```

### 枚举子集

当元素个数 `n <= 20` 左右，可以用 `mask` 表示一个子集。第 `i` 位为 1 表示选择第 `i` 个元素。

```java
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) != 0) {
            // 使用第 i 个元素
        }
    }
}
```

### 枚举某个集合的所有子集

这个模板常用于状态压缩 DP 中的“把集合拆成两部分”。

```java
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // sub 是 mask 的非空子集
}
```

## 复杂度与边界

- 位运算通常把集合操作从 O(n) 降到 O(1)，但前提是状态数量可控。
- Java `int` 只有 32 位，`long` 只有 64 位，位数超过时要换 `BitSet` 或数组。
- `1 << i` 在 `i >= 31` 时可能溢出，需要写成 `1L << i`。

## 易错点

- Java 有符号右移 `>>` 和无符号右移 `>>>` 不同。
- 位移优先级容易误判，复杂表达式加括号。
- 判断某一位是否为 1 要写 `(x & (1 << i)) != 0`，不要写成 `== 1`。

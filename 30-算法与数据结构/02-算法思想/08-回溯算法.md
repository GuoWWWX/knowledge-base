# 回溯算法

> [!abstract] 一句话总结
> 回溯是在决策树上 DFS，核心动作是选择、递归、撤销选择。

## 适用题型

- 子集、组合、排列。
- 棋盘搜索：N 皇后、数独。
- 路径枚举。
- 带约束的搜索。

## 模板

```java
void backtrack(List<Integer> path, boolean[] used) {
    if (path.size() == nums.length) {
        ans.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        backtrack(path, used);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

## 易错点

- 组合用 `startIndex`，排列用 `used`。
- 去重先排序，再区分同层去重和树枝去重。
- 撤销选择必须和选择操作对称。

## 三类高频模板

| 类型 | 关键状态 | 是否需要 `used` |
| ---- | -------- | --------------- |
| 子集 | `startIndex` | 通常不需要 |
| 组合 | `startIndex`、剩余目标 | 通常不需要 |
| 排列 | `used[]` | 需要 |

## 剪枝思路

- 排序后，如果当前选择已经超过目标，可以提前停止。
- 组合问题中剩余元素数量不足时可以提前停止。
- 去重时常用 `if (i > start && nums[i] == nums[i - 1]) continue;` 跳过同层重复选择。

## 复杂度表达

回溯复杂度通常不是简单 O(n)。面试中可以按搜索树解释：排列是 O(n · n!)，子集是 O(n · 2^n)，组合要结合结果数量和路径长度。

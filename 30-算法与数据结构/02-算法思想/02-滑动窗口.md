# 滑动窗口

> [!abstract] 一句话总结
> 滑动窗口用于连续子数组/子串问题，通过右扩和左缩维护窗口约束。

## 判断信号

- 题目要求连续区间。
- 需要最长、最短、计数或窗口内频次。
- 窗口扩张后可以通过收缩恢复合法状态。

## 模板

```java
int left = 0;
for (int right = 0; right < s.length(); right++) {
    add(s.charAt(right));
    while (windowInvalid()) {
        remove(s.charAt(left));
        left++;
    }
    updateAnswer(left, right);
}
```

## 易错点

- 先更新答案还是先收缩，取决于求合法窗口还是非法窗口。
- 最小覆盖类问题通常在窗口满足条件时收缩。
- 频次数组比 HashMap 更适合固定字符集。

## 两类模板

### 固定长度窗口

窗口长度固定为 `k` 时，右指针每走一步，左侧同步移出，常用于定长子数组最大和、字符串排列判断。

```java
for (int right = 0; right < n; right++) {
    add(right);
    if (right >= k) remove(right - k);
    if (right >= k - 1) update();
}
```

### 可变长度窗口

窗口长度不固定时，用 `while` 收缩到重新合法，常用于最长无重复子串、最短覆盖子串。

```java
for (int right = 0; right < n; right++) {
    add(right);
    while (invalid()) {
        remove(left++);
    }
    update();
}
```

## 复杂度

每个元素最多进窗口一次、出窗口一次，所以时间通常是 O(n)，空间取决于维护的频次结构。

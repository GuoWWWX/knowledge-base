## 📄 本领域文档约定

### 题解用专属模板

> 题解不用通用知识笔记模板，用 [[../99-模板/算法题解模板]]。

每道题记录：**题目 → 思路 → 复杂度 → 代码 → 易错点 → 同类题**。

### 命名规范

| 类型 | 格式 | 示例 |
| ---- | ---- | ---- |
| 题解 | `<序号>-LC<题号>-<题名>.md` | `01-LC0001-两数之和.md` |
| 专题总结 | `<序号>-专题-<主题>.md` | `03-专题-二分查找.md` |
| 模板 | `<序号>-模板-<主题>.md` | `05-模板-并查集.md` |

> 每个知识区按 `_index.md` 的顺序从 `01` 连续编号；`_index.md`、README 和总览文件不参与编号。

### 复盘机制

- 每道题标注首次完成日期 + 复习日期
- 用 `掌握度` 字段（⭐1~5）标记，定期重刷低星题
- 错题进 `03-刷题记录/` 的错题集

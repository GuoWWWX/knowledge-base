# 面试：大厂高频算法 Top 母题解法全景与秒杀策略

> [!abstract] 一句话总结
> 大厂面试算法考察的绝不是冷门偏门技巧，而是 **90% 集中在 LeetCode Top 100 的“母题模型”**。只要吃透双指针、快慢指针数学推导、二叉树后序遍历、股票状态机模型与拓扑排序，任何变形题皆可迎刃而解！

---

## 🎯 大厂算法面试“降维打击”四大心智

1. **链表问题优先考虑双指针与虚拟头节点（Dummy Head）**；
2. **二叉树问题 90% 本质是 DFS 递归（前中后序）或层序遍历（BFS 队列）**；
3. **区间和问题有负数必用“前缀和 + 哈希”，全正数优先用“滑动窗口”**；
4. **求最值与方案数优先识别“动态规划状态转移方程”**。

## 🔥 核心高频母题全景解析

### 母题 1: 三数之和（LC 15 排序 + 双指针去重神技）
> **题目要求**：给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足和为 0，且三元组不得重复。
>
> **核心破局与避坑**：
> 1. 暴力三重循环为 $O(N^3)$，不可接受。
> 2. **排序 + 双指针降维至 $O(N^2)$**：
>    - 先对数组排序：`Arrays.sort(nums)`；
>    - 遍历固定第一个数 `nums[i]`，若 `nums[i] > 0`，由于数组有序，后面两数必大于 0，和不可能为 0，直接 `break`；
>    - **第一重去重**：若 `i > 0 && nums[i] == nums[i - 1]`，跳过当前数；
>    - 左右双指针夹逼：`left = i + 1, right = n - 1`；
>    - 当 `sum == 0` 记录答案后，**必须执行第二重去重**：
>      `while (left < right && nums[left] == nums[left + 1]) left++;`
>      `while (left < right && nums[right] == nums[right - 1]) right--;`
>      随后 `left++`, `right--` 继续寻找下一组解。

### 母题 2: 环形链表 II（LC 142 寻找入环第一个节点数学推导）
> **题目要求**：给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。若无环返回 `null`。
>
> **严密数学公式推导（面试官最看重推理）**：
> ```text
> 设定参数：
> - 链表头到环入口的距离为 a；
> - 环入口到快慢指针首次相遇点的距离为 b；
> - 相遇点顺时针继续走完一圈回到环入口的距离为 c（环长 L = b + c）。
>
> 运动关系：
> - 快指针每次走 2 步，慢指针每次走 1 步；
> - 快指针速度是慢指针的 2 倍，相遇时快指针走过的路程必定是慢指针的 2 倍！
> - 慢指针路程：s = a + b
> - 快指针路程：f = a + n(b + c) + b （其中 n >= 1 为快指针在环内多跑的圈数）
>
> 数学推导：
> f = 2s  ===>  a + n(b + c) + b = 2(a + b)
>        ===>  a + n(b + c) + b = 2a + 2b
>        ===>  a = n(b + c) - b
>        ===>  a = (n - 1)(b + c) + c
> ```
> **结论与代码动作**：
> $a = (n - 1)L + c$ 告诉我们：**让一个新指针从链表头（`head`）出发，同时让慢指针从相遇点（`slow`）出发，两指针每次均只走 1 步，当它们在途中再次相遇的那一瞬间，所处的物理位置必定就是【环的入口节点】**！

### 母题 3: 二叉树的最近公共祖先（LC 236 LCA 后序遍历回溯）
> **题目要求**：给定一棵二叉树以及两个节点 `p` 和 `q`，找到它们的最近公共祖先（LCA）。
>
> **核心破局**：自底向上寻找祖先，天然依赖**二叉树的后序遍历（左右根）**！
> ```java
> class LCASolution {
>     public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
>         // 终止条件：若当前节点为空，或者当前节点恰好等于 p 或 q，直接返回当前节点
>         if (root == null || root == p || root == q) {
>             return root;
>         }
>
>         // 递归深入左右子树寻找
>         TreeNode left = lowestCommonAncestor(root.left, p, q);
>         TreeNode right = lowestCommonAncestor(root.right, p, q);
>
>         // 1. 若左右子树返回值均非空：说明 p 和 q 分别位于当前节点的两侧！当前节点就是 LCA！
>         if (left != null && right != null) {
>             return root;
>         }
>         // 2. 若只有一侧非空：返回那个非空的节点；若两侧皆空：返回 null
>         return left != null ? left : right;
>     }
> }
> ```

### 母题 4: 合并 K 个升序链表（LC 23 两种最优解法）
> **题目要求**：将 $K$ 个有序升序链表合并为一个有序大链表。
>
> **解法 A：优先队列小顶堆（$O(N \log K)$）**：
> - 维护一个大小为 $K$ 的最小堆：`PriorityQueue<ListNode> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a.val));`
> - 先将 $K$ 个链表的头节点全部入堆；
> - 每次弹出堆顶最小节点接入新链表，若该弹出节点有 `next`，立即将 `next` 补进堆中；直到堆空。
>
> **解法 B：归并分治思想（Divide and Conquer，$O(N \log K)$）**：
> - 将 $K$ 个链表两两配对合并（利用 LC 21 合并两个有序链表），第一轮将 $K$ 个缩减为 $K/2$ 个，递归直到只剩 1 个。
> - 优势：空间复杂度 $O(\log K)$，无需额外开辟优先队列容器，常数开销极小。

### 母题 5: 买卖股票的最佳时机全系列状态机（LC 121 / 122）
> **第一性原理**：每天结束时，账户只有两种持仓状态：
> - `dp[i][0]`：第 $i$ 天结束时，手中**未持有股票（现金状态）**的最大利润；
> - `dp[i][1]`：第 $i$ 天结束时，手中**持有股票（买入态）**的最大利润。
>
> **状态转移推导（以无限次交易 LC 122 为例）**：
> $$dp[i][0] = \max(dp[i - 1][0], \ dp[i - 1][1] + \text{prices}[i]) \quad \text{(昨天就没买，或今天卖掉)}$$
> $$dp[i][1] = \max(dp[i - 1][1], \ dp[i - 1][0] - \text{prices}[i]) \quad \text{(昨天就持有，或今天买入)}$$
>
> **空间压缩为两个变量（$O(1)$ 空间）**：
> ```java
> public int maxProfit(int[] prices) {
>     int cash = 0;              // 手中不持有股票的最大收益
>     int hold = -prices[0];     // 手中持有股票的最大收益
>     for (int i = 1; i < prices.length; i++) {
>         cash = Math.max(cash, hold + prices[i]);
>         hold = Math.max(hold, cash - prices[i]);
>     }
>     return cash;
> }
> ```

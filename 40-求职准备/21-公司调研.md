# 公司调研

> [!abstract] 一句话总结
> 用一页表把目标公司、岗位匹配度、技术栈和面试风险看清楚，避免盲投。

## 目标公司清单

| ---- | -------- | ------ | -------- | ---------- | ------ |

## 调研维度

| 维度 | 要看什么 | 简历/面试动作 |
| ---- | -------- | -------------- |
| 业务 | 产品形态、客户类型、是否有真实 AI 落地场景 | 准备一段“为什么投这家公司” |
| 岗位 | JD 关键词、必备技能、加分项、年限要求 | 对齐简历关键词，删掉无关表达 |
| 技术 | Java / Spring / RAG / Agent / 数据平台 / 可观测性 | 准备对应项目证据和追问答案 |
| 团队 | 业务团队、平台团队、算法团队还是交付团队 | 调整项目讲法和问题侧重点 |
| 风险 | 外包/驻场、业务稳定性、技术栈偏离、面试轮次 | 决定是否投递以及优先级 |

## 面试准备清单

- 找到 JD 中出现 2 次以上的关键词，映射到简历项目。
- 针对公司业务准备 1 个 AI 应用落地设想或 Java 后端优化案例。
- 把可能被深挖的问题补到 [[17-面试-项目类问题]]。
- 投递后在 [[20-投递记录]] 里记录渠道、状态和反馈。
